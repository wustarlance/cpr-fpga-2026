# 一、FSR 是什么

## 1.1 结构

```
        ┌───────────────────────────────┐
        │  ① 保护层（聚酯薄膜）           │
        ├───────────────────────────────┤
        │  ② 导电油墨层（上片）           │
        │     ·  ·  ·  ·  ·  ·  ·        │  ← 隔离点(spacer dots)
        │  ③ 电阻油墨层（下片）           │
        ├───────────────────────────────┤
        │  ④ 基板                        │
        └───┬───────────────────────┬───┘
         引线1                    引线2      ← 【不分极性】
```

一张 **0.3~0.5 mm 厚的柔性膜**，面积从几毫米到几十毫米见方，**只有两个引脚**。

## 1.2 原理：接触面积决定电阻

```
   不受力                     受力
   ┌─────────┐              ┌─────────┐
   │ ·  ·  · │  ← 两片     │▓▓▓▓▓▓▓▓▓│  ← 上片被压弯，
   │         │    被隔离     │▓▓▓▓▓▓▓▓▓│    两片之间接触
   │ ·  ·  · │    点撑开     │▓▓▓▓▓▓▓▓▓│
   └─────────┘              └─────────┘
   R > 1 MΩ                 R 急剧下降
```

⚠️ **不是压电效应，是纯电阻的接触变化。**

> 🔑 **它是无源电阻器件，内部没有程序。**
> 这一点直接满足方案 §15 的合规要求（「不能买带 MCU 的智能传感器模块」）。

## 1.3 ⭐ 四个必须知道的特性

| # | 特性 | 后果 |
|---|---|---|
| **1** | **高度非线性**（R-F 大致成反比幂律） | **不能线性换算成"厘米"** |
| **2** | **迟滞**：加力和卸力曲线不重合 | 同一深度，按下去和松开读数不同 |
| **3** | **个体差异大**：同批次也可能差几倍 | 换一片 FSR 就要重新标定 |
| **4** | **受受力面积影响**：压中心 vs 压边缘不同 | 手掌位置会影响读数 |

典型量级（**仅供感觉，务必实测手上那片**）：

| 状态 | 阻值量级 |
|---|---|
| 完全不按 | **> 1 MΩ** |
| 轻按 | 几十 kΩ |
| 中等 | 几 kΩ |
| 重按 | 几百 Ω ~ 1 kΩ |

## 1.4 ⭐ 为什么"只标定两个门限"是对的策略

因为上面四个毛病，**精确测深度不可能**：

| 想做的事 | 可行吗 |
|---|---|
| 精确测出"现在按了 5.3 cm" | ❌ 误差极大 |
| 测出"有没有按" | ✅ 容易 |
| 测出"浅 / 中 / 深"（粗分档） | ✅ **完全可行** |

**所以策略是：不算物理量，直接标定两个门限。**

```
垫 5cm 垫块压实 → 记 ADC 峰值 → T_low
垫 6cm 垫块压实 → 记 ADC 峰值 → T_high
```

> 🔑 **这个做法绕开了 FSR 的所有缺点**：不管它多非线性、多大迟滞、个体差多少 ——
> **反正我只需要两个点，把这两个点量出来就行。**

# 三、电路：为什么需要那个 10 kΩ 电阻

## 3.1 ⭐ 先纠正一个直觉误解

> ❌ "电阻能产生电压"
> ✅ **电阻不产生电压。电压是「电流流过电阻」产生的压降。**

欧姆定律：**U = I × R**
- **没有电流**流过 → 电阻两端**没有压降**（不管电阻多大）
- 有电流流过 → 电阻越大，同样的电流产生的压降越大

## 3.2 串联电路的两条铁律

```
   3.3V ──[ R1 ]──┬── M10
                  │
                [ FSR ]
                  │
                 GND
```

| 铁律 | 内容 |
|---|---|
| **① 电流处处相同** | R1 和 FSR 流过**同一个电流**（只有一条路） |
| **② 电压按电阻比例分** | 谁的电阻大，谁分到的压降多（U = I·R，I 相同） |

## 3.3 ⭐ 为什么"不要电阻"不行

```
   3.3V ──────────┬── M10（ADC 输入，高阻）
                  │
                [ FSR ]
                  │
                 GND
```

**ADC 输入是高阻** → 几乎不吃电流 → **I ≈ 0**

```
U_FSR = I × R_FSR ≈ 0 × R_FSR = 0
→ V_M10 = 3.3 − 0 = 3.3 V（恒定）
```

**⚠️ 无论 FSR 怎么变，M10 永远是 3.3 V。** 因为**没有电流，就没有压降**。

> 🔑 **FSR 的"电阻变化"必须先变成电流变化，才能变成电压变化。**
> **没有 R1 就没有稳定的电流回路。**

## 3.4 加上 R1 之后的完整推导

**第一步：算电流**（串联总电阻决定电流）

$$I = \frac{3.3}{R_1 + R_{FSR}}$$

**第二步：算 M10 的电压**（就是 FSR 上的压降）

$$V_{M10} = I \times R_{FSR} = \boxed{\,3.3 \times \frac{R_{FSR}}{R_1 + R_{FSR}}\,}$$

**第三步：看它怎么随按压变化**

**按压 → R_FSR ↓ → V_M10 ↓**

## 3.5 算账表（R1 = 10 kΩ）

| R_FSR | V_M10 | 状态 | 在有效窗口内？ |
|---|---|---|---|
| 1 MΩ | **3.27 V** | 不按 | ❌ 超上限 |
| 100 kΩ | 3.00 V | 轻触 | ❌ 略超（上限 2.97） |
| **90 kΩ** | **2.97 V** | — | 恰在上限 |
| 30 kΩ | 2.48 V | 浅按 | ✅ |
| **10 kΩ** | **1.65 V** | 中按 | ✅ |
| 3 kΩ | 0.76 V | 重按 | ✅ |
| **1.11 kΩ** | **0.33 V** | — | 恰在下限 |
| 1 kΩ | 0.30 V | 压到底 | ❌ 略超下限 |

## 3.6 ⭐ 有效窗口：**0.33 ~ 2.97 V**

文档表 2：**采样范围 = 0.1 × VREF ~ 0.9 × VREF**
板上 `ADC_VREF` 接 **VCCIO8 = 3.3 V**

$$0.1 \times 3.3 \sim 0.9 \times 3.3 = \mathbf{0.33\,V \sim 2.97\,V}$$

**→ 可用的 FSR 阻值窗口 ≈ 1.1 kΩ ~ 90 kΩ**

⚠️ **所以 `10 kΩ` 这个值可能需要改**（试 47k / 100k）。

**选值方法**（别猜，量出来）：

```
① 面包板上用【10kΩ 电位器】代替 FSR
② 万用表量节点电压
③ 调电位器，找到 5cm / 6cm 对应的位置，记下电压
④ 检查两点是否都在 0.33~2.97 V，且【分得开】
⑤ 不在窗口内 → 换分压电阻
```

## 3.7 8 bit 精度的含义

文档表 2：**输出 12 bit，有效精度 8 bit**

```
满量程 3.3 V ÷ 256 = 12.9 mV / 个有效码
可用窗口 2.64 V  →  约 205 个有效码
```

**两个门限建议隔 ≥ 0.3 V（≈23 个码）才稳。**

## 3.8 水压类比（最好懂）

| 电学 | 水学 |
|---|---|
| 电压 | 水压 |
| 电流 | 水流 |
| 电阻 | 管子粗细（越细阻力越大） |

两根**粗细不同的管子串联**：水流量相同，但每根管子消耗的水压**与其阻力成正比**。
**下管变细（FSR 受压）→ 中间接点水压变化** ✅

# 四、接线：接到 FPGA 的哪两个脚

## 4.1 芯片球位与当前接线位置

```
   ┌─────────────────────────────────┐
   │  FPGA 芯片（BGA 封装）           │
   │    ·  ·  ●M12  ·  ·             │  ← M12 是 BGA 球位标号
   └──────────────┬──────────────────┘     焊在板内，手碰不到
                  │  厂家在 PCB 上引到了 J2
                  ▼
        ┌──────────────────┐
        │  J2 扩展口 40 脚   │
        │   ...            │
        │   35 脚 ← ADC CH4  │  ← 当前采样节点
        │   29 脚 = 3.3V    │
        │   30 脚 = GND     │
        └──────────────────┘
```

`M12` 是芯片封装球位，`J2 第35脚` 是开发板扩展口位置；当前接线使用 CH4。板卡手册中的该网络名为 `GPIOB_30`，不要将其与 J2 第39脚的 `GPIOB_34`／CH6 混用。

## 4.2 完整接线图

```
   J2 脚 29 (3.3V)
        │
      ┌─┴─┐
      │3.3kΩ│ ← 电阻第 1 脚接 J2-29
      └─┬─┘     电阻【第 2 脚】接节点
        │
        ├──────────────→ J2 脚 35 (M12) = ADC_CH4
        │
      ┌─┴─┐
      │FSR│  ← 引线①接节点，引线②接 J2-30
      └─┬─┘
        │
   J2 脚 30 (GND)
```

**电阻的两个脚**：

| 电阻的脚 | 接到 | 是什么 |
|---|---|---|
| **第 1 脚** | **J2 第29脚** | **3.3V 电源** |
| **第 2 脚** | **节点**（＝J2 第35脚／M12／CH4） | **ADC 模拟输入** |

**面包板实际插法**：

```
  排 A（3.3V 排）← 杜邦线 → J2-29      电阻第 1 脚
  排 B（节点排） ← 杜邦线 → J2-35      FSR 引线① + 电阻第 2 脚
  排 C（GND 排） ← 杜邦线 → J2-30      FSR 引线②
```

**回路电流**：`I = 3.3/(3300 + R_FSR)` A；按 FSR 电阻趋近0估算，最大约1 mA。

# 五、ADC 内部是怎么处理外部信号的

## 5.1 ⭐ SAR = 逐次逼近 = **二分法猜数**

假设输入 2.0 V，参考 3.3 V，12 bit（4096 级）：

```
① 试 1/2 量程：3.3 × 1/2  = 1.650 V  →  2.0 > 1.650  →  bit11 = 1
② 试 3/4 量程：3.3 × 3/4  = 2.475 V  →  2.0 < 2.475  →  bit10 = 0
③ 试 5/8 量程：3.3 × 5/8  = 2.063 V  →  2.0 < 2.063  →  bit9  = 0
④ 试 9/16   ：3.3 × 9/16 = 1.856 V  →  2.0 > 1.856  →  bit8  = 1
...  继续细分，直到 12 位全部确定
```

**猜 12 次，就得到 12 位结果。**

## 5.2 硬件框图

```
   V_in ──┬──────────────────┐
          │            ┌─────▼─────┐
          │            │  比较器    │──→ 大/小
          │            └─────▲─────┘
          │            ┌─────┴─────┐
          │            │    DAC    │  ← 产生"猜测电压"
          │            └─────▲─────┘
          │            ┌─────┴─────┐
          │            │    SAR    │  ← 逐次逼近寄存器
          │            └───────────┘     记录每一位 + 控制下一次试哪个
         GND
```

| 部件 | 作用 |
|---|---|
| **采样保持** | 在 `soc` 那一刻**抓住**输入电压（转换期间不跟着变） |
| **比较器** | 比较 V_in 和 DAC 输出 |
| **DAC** | 根据 SAR 当前值产生"猜测电压" |
| **SAR** | 记录每一位结果，控制二分过程 |

## 5.3 `soc` / `eoc` 时序

```
clk    ┐_┌_┐_┌_┐_┌_┐_┌ ... （≤16 MHz）
soc    ___┌───────────────────  ← "开始转换" = 抓住输入，开始二分
eoc    ───┘          ┌────────  ← "转换完成" = 12 位都定了
dout   ══════════════╪════════  ← 结果
        └── N 个 clk ──┘
             ↑
      这 N 拍就是在做 N 次二分比较
```

⚠️ **文档没给 N 的确切值** → **上板实测标定**。

## 5.4 ⭐ 为什么"输出 12 bit，有效精度只有 8 bit"

文档注 1：

> ADC 的精度和参考电压关系非常紧密，需要板上提供**非常准确和干净的 VREF**，
> 精度控制在 **VDDA ± 0.2% 以内**。

- 3.3 V × 0.2% = **±6.6 mV** —— 很严的要求
- 而 12 bit 的 1 LSB = 3.3/4096 = **0.8 mV** —— 远小于噪声
- **所以低 4 位基本是噪声，不可信**

| **1** | SOC 采样间隔要小于 **10 µs**（采样率 ≥100 kHz）；大间隔采样需在 SOC 前 5 个时钟周期拉高 PD | 1 kHz 采样**不合规** | **改 200 kHz** |
| **2** | 「8 个通道输入**和用户 IO 复用**……未使用的通道可作普通 IO」 | 当前使用 M12／CH4，不再将该引脚用作数字输出 | 检查 |
| **3** | 「**尽量避免使用 ADC IO 相同 BANK 的数字 IO** 以减小噪声」 | 按键/拨码/蜂鸣器若同 BANK 会有噪声 | 查 BANK 划分 |
| **4** | 「相关 BANK 的 **VCCIO 应不低于 ADC 模拟电源电压**」 | VCCIO ≥ 3.3 V | 板上已满足 ✅ |

# 六、机械设计

## 6.1 ⚠️ 必须避免：弹簧和 FSR **并联**

**错误结构**（把 FSR 和弹簧都放在"压板—底板"之间）：

```
    压板
     │
  ┌──┴──┐        ← 弹簧 ×4
  │弹簧 │
  └──┬──┘
     │  ┌─────┐
     │  │ FSR │   ← FSR 贴底板中央
     │  └─────┘
   底板
```

**算一笔账**：

| 项 | 数值 |
|---|---|
| 弹簧需要的总刚度（20kg @ 60mm） | k = 196 N ÷ 60 mm = **3.27 N/mm** |
| **FSR 的等效刚度** | 0.2~0.5 mm 压缩量承受约 200 N → **≈ 1000 N/mm** |

$$F = (k_{spring} + k_{FSR}) \times x = (3.27 + 1000) \times 60 = \mathbf{60{,}196\ N = 6.1\ 吨}$$

> 🔴 **压板根本压不下去。** FSR 比弹簧硬约 **300 倍**，会变成"FSR 自己撑住压板、弹簧几乎没被压缩"
> —— **行程接近 0，读数和"按多深"毫无对应关系。**

**根因**：FSR 是**力**传感器，不是**位移**传感器。**它不能和弹簧并联，必须串联在力路径上。**

## 6.2 ✅ 正确结构：加一块「浮动板」

```
                        手掌
                         ↓
        ┌────────────────────────────────────┐
        │      压板  Φ180 × 8mm 亚克力         │
        │   ●                            ●   │
        │   ●                            ●   │
        └───┬──────────┬─────────┬───────┬───┘
            │          │         │       │
         弹簧①      弹簧②     弹簧③   弹簧④      ← 4 根并联（稳定、不歪）
            │          │         │       │
        ┌───┴──────────┴─────────┴───────┴───┐
        │      浮动板  Φ180 × 8mm 亚克力       │  ← 汇集弹簧载荷
        └────────────────┬───────────────────┘
                         │
                    ┌────┴────┐
                    │ Φ25 垫片 │  ← 分散弹簧端面压力
                    ├─────────┤
                    │  FSR    │  ← ★ 串在力路径上，承受【全部力】
                    └────┬────┘
                         │
        ┌────────────────┴───────────────────┐
        │         底板  Φ180 × 8mm             │
        └────────────────────────────────────┘
```

**力路径**：手掌 → 压板 → 弹簧×4 → 浮动板（汇总）→ FSR → 底板

| | 错误设计（并联） | ✅ 正确设计（串联） |
|---|---|---|
| 压板下压 60mm 需要 | **6.1 吨** ❌ | **20 kg** ✅ |
| FSR 承受的力 | 0.3% | **100%** ✅ |
| 行程 | ≈ 0 ❌ | **= 弹簧压缩量 = 60 mm** ✅ |

**关键机理**：FSR 自己只形变 0.2~0.5 mm → **浮动板几乎不下沉 → 压板位移 ≈ 弹簧压缩量** ✅

## 6.3 完整尺寸表

| 件 | 尺寸 | 材料 | 说明 |
|---|---|---|---|
| **压板** | **Φ180 × 8 mm** | 亚克力 | 接受手掌施力 |
| **浮动板** | **Φ180 × 8 mm** | 亚克力 | 汇集弹簧载荷 |
| **底板** | **Φ180 × 8 mm** | 亚克力 | 支撑导向与传感器 |
| **弹簧 ×4** | 见 6.5 | 压缩弹簧 | 分布半径 **R = 50 mm** |
| **导柱 ×4** | **M5 螺杆，长 160 mm** | 碳钢 | 只**导向**，不承重 |
| **导柱孔** | Φ5.5 mm | — | 比螺杆大 0.5 mm，自由滑动 |
| **限位螺母** | M5 ×12 | — | 限制最高位，防弹簧脱落 |
| **FSR 垫片** | **Φ25 × 2 mm** | 亚克力/金属 | 分散弹簧端面压力 |
| **FSR** | **30×60 mm，300 g～20 kg** | 无源电阻式 | 位于浮动板与底板之间 |

三块板的尺寸按现有装配更新；弹簧、导柱、垫片等其余尺寸为原选型参数，整体高度不由旧尺寸叠加推定。

> ⚠️ **不要省掉 Φ25 垫片** —— 否则弹簧端面会在 FSR 上造成应力集中，读数不稳甚至压坏。

## 6.4 压板直径选择

| 参考 | 尺寸 |
|---|---|
| 成人掌宽（拇指根~小指根） | **85 ~ 95 mm** |
| 手长（腕~中指尖） | 180 ~ 195 mm |
| CPR 按压接触区（掌根） | Φ70 ~ 90 mm |

| 直径 | 结果 |
|---|---|
| Φ120 | ⚠️ 掌宽就 85~95，**手掌会压到边缘**，容易压偏、压板翘 |
| **Φ180（当前装配）** | 手掌放在板面，掌根对准中心区 |
| Φ220+ | ❌ 板太大会变形，力臂长容易翘 |

**下界由掌宽定（≥150），上界由压板刚度定（≤200）→ Φ160~180 是甜点区。**

## 6.5 弹簧选型（**最容易翻车的一步**）

### 先算需求

| 项 | 数值 |
|---|---|
| 6 cm 时总力目标 | **20 kg = 196 N** |
| 最大行程 | **60 mm**（设计到 70 mm 留余量） |
| **4 根并联的等效总刚度** | k = 196 ÷ 60 = **3.27 N/mm** |
| **每根弹簧的刚度** | 3.27 ÷ 4 = **0.82 N/mm** |
| **每根在 6 cm 时受力** | 196 ÷ 4 = **49 N（5 kg）** |

### 参考规格（起点，不是终点）

```
线径    d  = 1.2 mm
外径    D  = 12 mm
有效圈数 n ≈ 14 圈
自由长度 L0 ≈ 90 mm
压到 60 mm 时 ≈ 49 N（每根）
```

### ⭐ 但**别信计算，一定实测**

弹簧标称刚度误差常达 ±20%，散装件更甚。

```
① 买几种不同刚度的弹簧（线径 1.0 / 1.2 / 1.5 各来几根）
② 把 1 根弹簧竖在【体重秤 / 厨房秤】上
③ 用直尺把它压到压缩 60 mm
④ 读秤的数值
⑤ 换算：每根读数 × 4 = 总力
⑥ 总力落在 15 ~ 25 kg → 合格
```

### 手感分档

| 总力 @ 6cm | 手感 | 判断 |
|---|---|---|
| < 10 kg | 一压到底，分不出 5/6cm | ❌ 太软 |
| **15 ~ 25 kg** | **有明显行程和力度** | ✅ **合适** |
| > 35 kg | 按不动 | ❌ 太硬 |

> 📌 **不要追求真实 CPR 的 50 kg** —— 训练盒练的是**节奏与幅度**，不是力气。

## 6.6 装配步骤（**从下往上叠，顺序别乱**）

```
① 底板四角钻/切 Φ5.5 mm 孔（对应 R=50mm 的四个导柱位）
② M5 螺杆从下面穿过底板，用【双螺母】锁死在底板上
③ 把 FSR 用双面胶贴在底板【中央】
④ FSR 上放 Φ25 mm 垫片
⑤ 浮动板四角穿螺杆 → 落在 FSR 上
⑥ 放 4 根弹簧在浮动板上（R=50mm 位置）
⑦ 压板四角穿螺杆 → 压在弹簧上
⑧ 每根螺杆顶端加一个螺母（限位，防压板弹飞）
⑨ FSR 两根引线从底板边缘引出，分别接采样节点和J2-30；采样节点接J2-35
```

## 7.1 `adc_ctrl.v` —— 读 ADC

```verilog
// adc_ctrl.v —— EG_PHY_ADC 时序状态机
// 严格遵守官方 TN304 §5：SOC 间隔 < 10µs（采样率 ≥ 100 kHz）
module adc_ctrl #(
    parameter CLK_HZ    = 16_000_000,   // ADC 工作时钟（≤16 MHz）
    parameter SAMPLE_HZ =    200_000    // 目标采样率（≥100 kHz）
)(
    input  wire        clk,        // adc_clk
    input  wire        rst,
    output reg  [11:0] adc_val,    // 转换结果
    output reg         adc_valid   // 一拍有效脉冲
);
    localparam GAP = CLK_HZ / SAMPLE_HZ;      // 16M/200k = 80 拍

    localparam S_START = 2'd0, S_WAIT = 2'd1, S_GAP = 2'd2;

    reg  [1:0]  state;
    reg  [15:0] gap_cnt;
    reg         soc_r;
    wire        eoc;
    wire [11:0] dout;

    // ================= ADC 原语 =================
    EG_PHY_ADC #(
        .CH1  ("ENABLE"),     // ★ 通道 1 = M10（J1 第 16 脚）
        .VREF ("ENABLE")      // ★ 参考电压使能
    ) u_adc (
        .clk  (clk     ),
        .pd   (1'b0    ),     // ★ 1'b0 = 正常工作
        .s    (3'd1    ),     // ★ 选通道 1（必须与 CH1 对应）
        .soc  (soc_r   ),
        .eoc  (eoc     ),
        .dout (dout    )
    );

    // ================= 时序状态机 =================
    always @(posedge clk or posedge rst) begin
        if (rst) begin
            state <= S_START; soc_r <= 1'b0; gap_cnt <= 16'd0;
            adc_val <= 12'd0; adc_valid <= 1'b0;
        end else begin
            adc_valid <= 1'b0;                 // 默认失效（单拍脉冲）
            case (state)
                S_START: begin
                    soc_r <= 1'b1;             // 发起转换
                    state <= S_WAIT;
                end
                S_WAIT: begin
                    soc_r <= 1'b0;
                    if (eoc) begin             // ★ 等到转换完成
                        adc_val   <= dout;     // 锁存结果
                        adc_valid <= 1'b1;     // 输出一拍有效
                        gap_cnt   <= 16'd0;
                        state     <= S_GAP;
                    end
                end
                S_GAP: begin                   // 等够采样间隔
                    if (gap_cnt >= GAP[15:0]-16'd1) state   <= S_START;
                    else                            gap_cnt <= gap_cnt + 16'd1;
                end
            endcase
        end
    end
endmodule
```

**换到 J2 的 M12**：改 `.CH4("ENABLE")` 和 `.s(3'd4)`。

## 7.2 `peak_detect.v` —— 判断深度

```verilog
// peak_detect.v —— 双门限施密特 + 峰值跟踪 + 三级评级
module peak_detect #(
    parameter [11:0] T_TRIG = 12'h200,   // 进入"按压中"的门限（低，高于噪声底）
    parameter [11:0] T_LOW  = 12'h400,   // 5cm 门限（标定得到）
    parameter [11:0] T_HIGH = 12'h600    // 6cm 门限（标定得到）
)(
    input  wire        clk,
    input  wire        rst,
    input  wire [11:0] adc_val,
    input  wire        adc_valid,
    output reg  [11:0] peak_val,     // 本次按压的峰值
    output reg         peak_valid,   // 一拍脉冲：一次按压结束
    output reg  [1:0]  depth_grade   // 0=太浅 1=正确 2=过深
);
    localparam IDLE = 1'b0, TRACK = 1'b1;

    reg        state;
    reg [11:0] peak_r;

    // ★ 退出电平 = 峰值的 75%：用【移位】代替乘法/除法
    wire [11:0] exit_level = peak_r - (peak_r >> 2);   // peak_r × 0.75

    always @(posedge clk or posedge rst) begin
        if (rst) begin
            state <= IDLE; peak_r <= 12'd0;
            peak_val <= 12'd0; peak_valid <= 1'b0; depth_grade <= 2'd0;
        end else if (adc_valid) begin
            peak_valid <= 1'b0;
            case (state)
                // ---------- 等按压开始 ----------
                IDLE: begin
                    if (adc_val >= T_TRIG) begin
                        state  <= TRACK;
                        peak_r <= adc_val;
                    end
                end
                // ---------- 跟踪峰值 ----------
                TRACK: begin
                    if (adc_val > peak_r)
                        peak_r <= adc_val;              // 刷新峰值

                    if (adc_val < exit_level) begin     // ★ 回落 → 本次结束
                        state      <= IDLE;
                        peak_val   <= peak_r;
                        peak_valid <= 1'b1;
                        // ---- 用峰值评级 ----
                        if      (peak_r <  T_LOW ) depth_grade <= 2'd0;  // 太浅
                        else if (peak_r <  T_HIGH) depth_grade <= 2'd1;  // 正确
                        else                       depth_grade <= 2'd2;  // 过深
                    end
                end
            endcase
        end
    end
endmodule
```

**⭐ 两个设计要点**

| 要点 | 为什么 |
|---|---|
| **三个门限**（T_TRIG / T_LOW / T_HIGH） | 只用 T_LOW 进的话，"太浅"永远测不出来（因为进不去） |
| **`exit_level` 用移位** | `peak_r >> 2` = ÷4 → `peak_r - (peak_r>>2)` = ×0.75。**不用乘除法** |

# 八、标定流程

## 8.1 垫块塞在哪里

```
        压板
   ┌─────┬───────┬─────┐
   │     │       │     │
 [垫块]  │  弹簧  │  [垫块]   ← 5cm 或 6cm 高
   │     │       │     │
   └─────┴───────┴─────┘
        底板
```

⚠️ **必须塞在「压板边缘和底板之间」**（外圈没弹簧的地方）。

**为什么不能塞在 FSR 旁边**：那样力会从垫块**旁路**，FSR 读不到真实值。

**垫块怎么做**：5cm / 6cm 高的木块、亚克力条，或书叠出来。**精度 ±2 mm 就够**（只分三档）。

## 8.2 标定表

| 步 | 做什么 | 记什么 |
|---|---|---|
| 1 | 压板两侧各塞 **50 mm 垫块** | — |
| 2 | **用力压实**（让压板完全贴住垫块） | 记 ADC 读数 → **`T_low`** |
| 3 | 换成 **60 mm 垫块**，压实 | 记 ADC 读数 → **`T_high`** |
| 4 | 检查 | 两点都在 **0.33~2.97V** 对应区间内，且**差 ≥ 0.3 V** |

**`T_TRIG` 怎么定**：不受力时看 ADC 的**噪声峰值**，取它的 **2~3 倍**。

## 8.3 判定表（写进 `peak_detect.v`）

```
ADC 峰值 <  T_low        → 太浅（黄）
T_low ≤ 峰值 < T_high    → 正确（绿）
ADC 峰值 ≥ T_high        → 过深（红）
```

## 8.4 调试顺序（**照这个来，别跳步**）

| 步 | 做什么 | 验收 | 依赖 |
|---|---|---|---|
| **1** | ⭐ **用 10kΩ 电位器代替 FSR** | 屏幕上 ADC 数值随旋钮**单调变化** | 只要板子 |
| **2** | 量出 **soc → eoc 的拍数 N** | 得到确切值写进代码 | 步 1 |
| **3** | 面包板上接 FSR + 分压 | 手压时数值变化 | FSR |
| **4** | 垫 5cm / 6cm 垫块，记录 | 得到 `T_low` / `T_high` | 机械件 |
| **5** | 装弹簧 + 压板，连续按压 | 评级跟手、不重复计数 | 全部 |

> ⭐ **第 1 步单独先做** —— 它把"片内 ADC 到底能不能用"这个**唯一的技术未知项**
> 半小时解决掉，**且完全不依赖机械件**。

| **11** | **垫块塞在 FSR 旁边** | 力被旁路，标定错误 | 塞在**压板边缘** |

# 十一、保底方案

如果 FSR 路线不顺（标定难、机械做不出），按优先级退回：

| 方案 | 说明 | 代价 |
|---|---|---|
| **① 微动开关阵列** | 压板下压带动滑杆，两条不同长度的挡片压下两个开关。**纯数字、零标定、零模拟电路** | 只能分三档；机械精度要试 |
| **② 板载按键** | 直接用板载 4 键 | 互动降级，但**作品仍完整成立** |

**方案 §16 已把这条列为风险应对** —— 保底不是失败，是设计的一部分。
