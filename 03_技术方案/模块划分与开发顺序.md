# 模块划分与开发顺序

> 决定「哪些用 IP、哪些自己写」，以及按什么顺序推进
> 适用：视障无障碍信息终端 | 平台：安路 HX4S20C | 日期：2026-09-14

---

## 一、判断原则

> **和「芯片物理特性」绑定的 → 用 IP**
> **是「你的算法与逻辑」的 → 自己写**

前者你写不出来（或代价极高），后者才是作品的价值所在。

**而且有一条规律**：

| 用 IP 的部分 | 自己写的部分 |
|---|---|
| 不产生评分 | **产生评分** |
| 工程师都会做 | **区分队伍水平** |

赛题要求"算法、控制逻辑及数据处理流程应在 FPGA 中自主编程实现"——**这条要求在保护你们的作品价值**。

## 二、逐模块决策表

| # | 模块 | 决策 | 理由 | 难度 |
|---|---|---|---|---|
| 1 | **PLL**（像素时钟 / TMDS 5×） | 🏭 **必须用 IP** | 模拟电路，Verilog 描述不了 | ⭐ |

| 4 | **HDMI 发射核** | 🔒 **只能用加密 IP** | 高速串行 + 厂商专用电路 | ⭐ |
| 5 | SPI 主机（读 TF 卡） | ✍️ 自己写 | 协议简单，几十行 | ⭐⭐ |
| 6 | FAT32 目录解析 | ✍️ 自己写 | 只需"按文件名找扇区"，可简化 | ⭐⭐⭐ |
| 7 | BMP 解码 | ✍️ 自己写 | 读文件头 + BGR 顺序 + 行对齐 | ⭐⭐ |
| 8 | **字模渲染引擎** | ✍️ **必须自己写** | ⭐ **项目核心，无现成 IP** | ⭐⭐⭐⭐ |
| 9 | **图层叠加 / 底衬** | ✍️ **必须自己写** | ⭐ **项目核心** | ⭐⭐⭐ |
| 10 | 色彩查表（LUT） | ✍️ 自己写 | 一行代码 | ⭐ |
| 11 | 字形缩放 | ✍️ 自己写 | 最近邻起步，双线性进阶 | ⭐⭐⭐ |
| 12 | **页面调度状态机** | ✍️ **必须自己写** | ⭐ **项目核心** | ⭐⭐⭐ |
| 13 | 转场特效（淡入淡出） | ✍️ 自己写 | 复用图层叠加的 Alpha 通路 | ⭐⭐ |
| 14 | 按键消抖 | ✍️ 自己写 | 简单 | ⭐ |
| 15 | I2S 音频打包 | ✍️ 自己写 | 分频 + 移位 | ⭐⭐⭐ |
| 16 | 上电复位（POR） | ✍️ 自己写 | 简单，但决定稳定性 | ⭐⭐ |

**统计：3 个用 IP，13 个自己写。**

## 三、三类 IP 怎么用

### ① PLL（硬核 IP）

**操作**：TD 菜单 `Tools → IP 生成向导` → 选 PLL → 填输入/输出频率 → 生成

**填表就行，不写代码。**

**推荐参数**（可参考参考工程，但**必须用 TD 6.2.3 重新生成**）：

| PLL | 输入 | 输出 | 用途 |
|---|---|---|---|
| `video_pll` | 50 MHz | **25.175 MHz** | 像素时钟（640×480@60Hz） |
| | | **125.875 MHz** | TMDS 5× 串行时钟 |
| `sys_pll` | 50 MHz | 100 MHz | 系统时钟 |
| | | 125 MHz | SDRAM 时钟 |

> ⚠️ **必须用当前 TD 版本生成**。参考工程里的是 TD 5.6 生成的，会被 6.2.3 丢弃（这是参考工程跑不起来的根本原因）。

### ② SDRAM 控制器（硬核 IP）

**操作**：IP 向导 → 选 SDRAM 控制器 → 填数据位宽、地址位宽、时序参数

**时序参数从哪来**：`6_EG4S20数据手册` 里的 SDRAM 时序表，或参考例程的 `sdram.ipc` 参数。

### ③ HDMI 发射核（加密 IP）

**没得选**，只能调用。参考例程里有现成的 wrapper（`hdmi_phy_warpper.v`），照着接接口即可。

**它是你们的边界**：把接口对上就行，内部永远看不到。

## 四、系统分层：哪里用 IP，哪里自研

```
┌───────────────────────────────────────────────┐
│  ✍️  自研层（评分来源）                          │
│                                                 │
│   字模渲染引擎  ·  图层叠加  ·  色彩查表          │
│   字形缩放     ·  页面调度  ·  转场特效          │
│   BMP 解码     ·  FAT32 简化解析  ·  SPI 主机    │
│   I2S 打包     ·  按键消抖  ·  上电复位          │
├───────────────────────────────────────────────┤
│  🏭  IP 层（基础设施）                           │
│                                                 │
│   PLL ×2   ·   SDRAM 控制器   ·   异步 FIFO      │
├───────────────────────────────────────────────┤
│  🔒  加密 IP（只能调用）                         │
│                                                 │
│   HDMI 1.4b 发射核                               │
├───────────────────────────────────────────────┤
│  ⚙️  芯片原语（TD 提供，IP 内部调用）             │
│                                                 │
│   EG_PHY_PLL   ·   EG_LOGIC_BUFG   ·   ERAM      │
└───────────────────────────────────────────────┘
```

**你们的战场在第三层往上。**

## 五、开发顺序（关键：别倒过来）

**先用 IP 把地基铺好，再自研上层。**

### 阶段 1：配 IP（1~2 天）

- [ ] 用 TD 向导生成 `video_pll`（25.175 / 125.875 MHz）
- [ ] 生成 `sys_pll`（100 / 125 MHz）
- [ ] 生成 SDRAM 控制器
- [ ] 跑通综合，确认无 black box

**判据**：**能生成位流**，Console 无黑盒错误。

### 阶段 2：打通显示链路（约 1 周）

- [ ] 接 HDMI 发射核
- [ ] 先显示**彩条**（不接 TF 卡）
- [ ] 调通 TMDS 时序

**判据**：**显示器出现画面**（哪怕是彩条）。

> 这是**整个项目的心理转折点**。一旦看到画面，后面都是"往上加模块"。

### 阶段 3：媒体读取（约 1.5 周）

- [ ] SPI 主机读 TF 卡扇区
- [ ] FAT32 简化解析（按文件名找扇区）
- [ ] BMP 解码
- [ ] 数据写入 SDRAM 帧缓存

**判据**：**屏幕上出现 TF 卡里的图**。

### 阶段 4：核心功能（约 2 周）⭐ 重头戏

- [ ] **字模渲染引擎**（读字库 → 渲染到帧缓存）
- [ ] 图层叠加 + 文字底衬
- [ ] 字形缩放
- [ ] 页面调度状态机
- [ ] 色彩查表（高对比模式）

**判据**：**能显示带大字的信息页**——场景成立。

> ⚠️ **字模渲染留足时间**。这是最难的一块，也是作品的核心。

### 阶段 5：音频 + 交互（约 1 周）

- [ ] I2S 音频打包 → HDMI 数据岛
- [ ] 音画同步（页面与音轨绑定）
- [ ] 按键：切页 / 模式切换 / 重播
- [ ] 切换时加音量包络，避免爆音

**判据**：**按键切换时画面与语音同步变化**。

> 到此**四项基础要求全部完成**。

### 阶段 6：稳定性 + 扩展 + 交付（约 1 周）

- [ ] 上电分级复位，规避花屏
- [ ] TF 卡读取超时保护 + 异常自恢复
- [ ] 淡入淡出转场
- [ ] 连续运行 1 小时测试
- [ ] 作品报告 + 演示视频

**判据**：**连续运行不花屏、不卡死**。

## 七、四个避坑提醒

### ① IP 必须用当前 TD 版本生成

**不要**把参考工程里的 `.ipc` 直接拿来用。那是 TD 5.6 时代的，会被 6.2.3 丢弃——**这就是参考工程跑不起来的根本原因**。

**要用向导重新填参数生成。**

### ② IP 生成后放在 `al_ip/` 目录

TD 的规矩。放别处容易在工具升级时被丢。

### ③ 自研模块先仿真再上板

ysyx 的仿真能力在这里要发挥作用。

**字模渲染、图层叠加、状态机这些，先在 Verilog 仿真里验证逻辑，比上板调试快十倍。**

### ④ 别在参考工程上"改改交差"

它是 TD 5.6 时代的工程，跨了太多代。

**只能当"地图"读，不能当"地基"用。**

