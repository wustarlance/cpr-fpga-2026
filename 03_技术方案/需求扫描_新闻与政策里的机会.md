# 需求扫描：新闻与政策里，哪些领域正好需要这种设备

> 方法：不看"我能做什么"，而是从**2025—2026 年的新闻与政策文件**里倒查——哪些领域正在被**强制要求**或**安全倒逼**着去"把信息显示出来"。
> 再用三个筛子过滤：**新闻依据是否硬** / **是否严格契合 FPGA 特点** / **基础 4 条 + 扩展 5 条能否自然覆盖**。

---

## 一、三个筛子

### 筛子 1：需求刚性

| 等级 | 类型 | 特征 |
|---|---|---|
| ★★★★★ | **政策强制** | 文件点名必须公示/标示，不做出事（被罚、被查） |
| ★★★★☆ | **安全倒逼** | 官方把某种缺失列为安全隐患 |
| ★★★☆☆ | 服务提升 | "提升体验"，不做也能过 |

### 筛子 2：是否严格契合 FPGA 特点

赛题原话：FPGA 的优势是「**并行处理、实时控制、低延迟显示、音画同步及多源信息融合**」。

| 特点 | 什么场景才用得上 |
|---|---|
| **多源信息融合** | 必须同时汇入**两路以上**数据（如：SD 卡素材 + 本地接口数据） |
| **低延迟显示** | 数据一到就得立刻上屏，不能等 |
| **音画同步** | 语音与画面必须严格对拍 |
| **并行处理** | 多层画面同时在线合成 |
| 确定性时序 | 滚动/刷新不能抖，或要求长期无故障 |

**只用"播放图片"是喂不饱 FPGA 的**，必须有多源融合或音画同步，才叫"严格契合"。

### 筛子 3：基础 4 条 + 扩展 5 条

基础：核心功能 / 稳定性鲁棒性 / **基础音频输出** / 工程规范性
扩展：①图层叠加与字幕 ②轮播与转场 ③自适应缩放 ④实时调节与 OSD ⑤音频可视化

## 四、推荐

| 想突出什么 | 选它 | 理由 |
|---|---|---|
| **FPGA 特点最契合 + 撞车率最低** | **① 户外健身器材使用指导** | 低功耗、太阳能、常年不死机，是 FPGA 架构优势最直接的兑现；SD 卡合理性满分 |
| **新闻最热、痛点最具体、多源融合最强** | **② 快递驿站取件引导** | 新闻里有大量可直接引用的痛点细节；"不依赖 App"与监管风向完全一致；多源融合（卡+接口）天然成立 |
| **政策刚性最强（文件点名"电子屏幕"）** | **③ 养老机构收费公示** | 唯一一条政策原文直接写出"电子屏幕"的领域，但技术纵深一般 |

**我的建议：② 快递驿站取件引导。**

三个理由：

1. **新闻依据最具体**——不用自己论证痛点，报道里有"三四个蓝灯分不清""灯灭了三次""队伍排到门外"这样的原话，答辩时直接引用
2. **监管风向站在我们这边**——邮政管理局明确要查"强制下载 App"，而我们的方案**正是"不用下载 App"的那一条路**
3. **多源信息融合天然成立**——SD 卡素材（货架图、宣传）+ 本地接口数据（包裹位置），两路在 FPGA 内合成，**这是喂饱 FPGA 的正经需求**，不是硬凑

## 五、被筛掉的领域及原因

| 领域 | 为什么筛掉 |
|---|---|
| **餐饮"互联网+明厨亮灶"** | 政策很硬（总局令第 123 号，2026-06-01 施行），但要求**布设高清摄像头公开后厨实时画面**——需要**视频输入**，而 HX4S20C 没有视频输入通路，**硬件上做不了** |
| **智慧农业 / 大棚控制** | 主要是传感器与执行器需求，显示是附属 |
| **交通诱导屏** | 需要接入交通数据平台，且属大型工程 |
| **政务大厅综合引导** | 系统集成属性强，单设备价值低 |
