> 起因：之前的简介有两个硬伤——**没有体现 FPGA 的独特优势**，**没有逐条对上评分标准**。

## 一、赛题原文到底要什么

### 1.1 赛题要求（1.3）中的优势表述

> 「系统需体现 FPGA 在**并行处理、实时控制、低延迟显示、音画同步及多源信息融合**等方面的优势，并形成稳定的运行状态和良好的现场演示效果。」
> 「参赛作品中所展示的**所有算法、控制逻辑及数据处理流程应在 FPGA 中自主编程实现**。……**不得带有额外处理器（无论用于辅助控制还是算法预处理）**。」

### 1.2 赛题简介（1.2）中对 FPGA 优势的定义

> 「与依赖通用处理器的软件栈方案相比，FPGA 方案能够在保证较低系统复杂度的同时，实现**更确定的时序、更低的显示延迟和更高的系统可靠性**。」

### 1.3 评分标准：基础要求（4 条）

| # | 基础要求 |
|---|---|
| 1 | 核心功能完整性 |
| 2 | 显示稳定性与鲁棒性 |
| 3 | **基础音频输出** |
| 4 | 系统工程规范性 |

### 1.4 评分标准：扩展要求（5 条，加分项）

| # | 扩展要求 | 计分规则 |
|---|---|---|
| ① | 图层叠加与字幕效果（**动态文字**如时间戳或标语、多图层混合、**平滑滚动**） | 完成 1 项得一定分值；<br>完成 2 项且效果良好得扩展部分一半以上；<br>完成 3 项及以上且完成度高得较高分；<br>完成度高、创新性突出可满分 |
| ② | 图片轮播与转场特效（淡入淡出、滑动，画面连续） | |
| ③ | 图片自适应缩放显示（不同分辨率图片读取与缩放，鼓励优化缩放质量） | |
| ④ | **实时参数调节与 OSD 信息叠加**（板载开关或按键调节亮度、对比度等，并**在画面上呈现参数变化信息**） | |
| ⑤ | 音频可视化表现（频谱或波形叠加于视频画面） | |

## 二、逐条对照：我们做到了什么、漏了什么

| 赛题要求 | 我们的设计 | 状态 |
|---|---|---|
| 基础1 核心功能完整性 | 多幅图像播放 + HDMI 显示 | ✅ |
| 基础2 显示稳定性与鲁棒性 | 无操作系统、硬件流水线、确定性时序 | ⚠️ **简介里完全没写** |
| 基础3 **基础音频输出** | I2S / HDMI 音频（参考工程现成） | ⚠️ **之前没强调，必须补** |
| 基础4 系统工程规范性 | 模块化划分、时序约束、双缓冲 | ⚠️ 没写 |
| 扩展① 图层叠加与字幕 | 标注层透明色键控叠加 ✅<br>**动态文字与平滑滚动** ❌ | ⚠️ **漏一半** |
| 扩展② 轮播与转场 | 淡入淡出 / 滑动切换 | ✅ |
| 扩展③ 自适应缩放 | 相位累加实时缩放 | ✅ |
| 扩展④ **实时调节与 OSD** | **完全没做** | ❌ **漏，但成本极低** |
| 扩展⑤ 音频可视化 | 没做 | ❌ |

### 结论：三个漏项，成本都极低

> **我上一版为了"简化"，恰好把赛题点名要的、且最便宜的三样东西砍掉了。**

| 漏项 | 属于 | 成本 | 实现 |
|---|---|---|---|
| **音频输出** | 基础要求（不做直接扣分） | 低 | 参考工程 I2S 模块现成 |
| **动态文字 + 平滑滚动** | 扩展① | **几乎为零** | 滚动就是地址偏移；文字用片内点阵字库渲染 |
| **亮度/对比度调节 + OSD 参数显示** | 扩展④ | **极低** | 亮度是像素加减，对比度是移位/乘法近似；OSD 是矩形填充 + 字库 |

**补上这三样，扩展①~④ 就凑齐 4 项**，按计分规则属于"完成 3 项及以上且具有较高完成度"。⑤ 音频可视化作为冲刺。

## 四、重写后的作品简介

### ★ A_逐条对应版 —— 486 字（含换行）/ 484 字（去空白）

> 结构：**政策与痛点 → FPGA 优势 + 基础要求 → 扩展要求逐条列**。评委按评分表对照，一条不落。

```
工业和信息化部在“十五五”新型工业化部署中提出，推出轻量化、低成本、易部署的解决方案。当前制造业多品种小批量生产成为常态，工位换型频繁，纸质作业指导书更新慢、易用错版。
本作品是一台工位电子作业指导终端，用FPGA并行流水线实现通用播放器难以做到的低延迟与确定性显示。以国产安路EG4S20为核心，全部算法与控制逻辑在FPGA内自主编程实现，不含处理器。终端扫描SD卡图像资源、解析BMP文件并存入SDRAM帧缓存，经HDMI同时输出视频与音频；640×480下每秒1843万像素的取址、双层读取、透明色比较与合成均在像素时钟内一拍完成，按键响应下一帧即变，上电不到一秒出画面；无操作系统，不存在死机、病毒与文件损坏。
扩展要求逐条实现：①图层叠加与字幕——标注层以透明色键控叠加，提示文字由片内点阵字库实时渲染并平滑滚动；②轮播转场——淡入淡出与滑动切换；③自适应缩放——任意分辨率源图实时缩放适配HDMI输出；④实时调节与OSD——按键调节亮度对比度并同步显示参数变化；⑤音频可视化——以多段滤波器组提取音频能量生成频谱条叠加于画面。换型只需替换SD卡，无需重新综合。
```

本作品是一台基于安路EG4S20的工位电子作业指导终端，全部算法、控制逻辑与数据处理流程均在FPGA内自主编程实现，不含任何处理器。

```
为什么用FPGA做一块工位看板？
通用处理器方案要操作系统、要启动、要散热风扇，断电重启还要等；而在多品种小批量的车间里，工位换型频繁、粉尘油雾重、供电不稳，设备需要的是低延迟、确定和不出故障。
本作品是一台工位电子作业指导终端，全部算法与控制逻辑在国产安路EG4S20内自主编程实现，不含任何处理器。终端从SD卡扫描图像资源、解析BMP文件并存入SDRAM帧缓存，经HDMI同时输出视频与音频；每个像素的双层读取、透明色键控、合成与缩放全部由硬件流水线一拍完成，640×480下每秒处理1843万像素，按键响应下一帧即变，上电不到一秒出画面，没有操作系统，也就没有死机、病毒与文件损坏。
按题目扩展要求，作品实现图层叠加与平滑滚动字幕、淡入淡出与滑动转场、任意分辨率自适应缩放、按键调节亮度对比度并同步显示参数变化（OSD），以及基于多段滤波器组的音频频谱可视化。换型只需替换SD卡，无需重新综合与烧写。
```

## 五、一个需要你决策的选题风险 ⚠️

赛题 1.2 在介绍应用价值时，列举的场景是：

> 「**数字广告牌、商业展陈终端、应急信息发布、车载辅助显示及教育演示**」

**"工业 HMI / 工位终端"不在这个列表里。** 1.3 要求的是"自主设计并实现一个具有明确应用场景的展示系统"，并未限定必须在列表内，所以工业场景**不算跑题**；但如果想最大程度贴题，可以把场景措辞往列表靠：

| 方案 | 场景表述 | 评价 |
|---|---|---|
| A | 保持"工位电子作业指导终端" | 痛点最真实、政策抓手最硬；但不在赛题列举范围内 |
| B | 改为"教育演示"（如实训室操作指导） | 落在赛题列举范围内，**音频可视化也更自然**，痛点稍弱 |

**我的建议**：如果在意贴题度，选 **B**——"实训室/产线培训的作业指导终端"，既保留工业内容的实操价值，又落在"教育演示"这个赛题明确列举的场景里，而且实训场景下**语音讲解与音频可视化都非常自然**。
