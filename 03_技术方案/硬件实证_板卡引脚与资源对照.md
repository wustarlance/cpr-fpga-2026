## 一、结论速览（推翻/确认了哪些判断）

| 问题 | 结论 | 影响 |
|---|---|---|
| **按键够不够** | ✅ **板载 4 个独立按键 + 4 位拨码开关 = 8 路数字输入** | **不需要长短按组合，也不需要外接按键盒** |
| **有没有 ADC** | ✅ **芯片自带 8 通道 12 位 SAR ADC，且通道引脚引到了扩展口** | **按压盒可用力敏电阻直采，不需要外置 ADC** |
| **音频怎么出声** | ✅ **板载蜂鸣器(H11) + HDMI 音频 + VGA 旁路**；WM8731 走扩展口 | 基础要求 3 有多种实现路径 |
| **几路 HDMI** | ✅ **两路**：HDMI A 口（**可作输入或输出**）、HDMI B 口 | 参考工程用的是 B 口 |
| **资源够不够** | ✅ LUT/IO 充裕，⚠️ **块 RAM 是唯一瓶颈** | 字库只做用到的字 |
| **板载有没有 ADC 芯片** | ❌ **没有**。AD/DA 需外接模块走扩展口 | 但片内 ADC 更省，够用 |

### 4.1 两路 HDMI

| 信号 | 引脚 | 信号 | 引脚 |
|---|---|---|---|
| HDMIA_D2_P / N | **B3 / D3** | HDMIA_D0_P / N | **F5 / F4** |
| HDMIA_D1_P / N | **E3 / E4** | HDMIA_CLK_P / N | **K1 / J1** |
| HDMIA_SCL | **P1** | HDMIA_SDA | **R1** |
| HDMIA_HPD | **K2** | HDMIA_CEC | **K3** |

**HDMI B 口**（参考工程用的就是这个）

| 信号 | 引脚 |
|---|---|
| HDMI_CLK_P | **C3** |
| HDMI_D0_P | **G5** |
| HDMI_D1_P | **F1** |
| HDMI_D2_P | **E1** |

> 官方例程 `31_hdmi_tx_display_A` 里同时给出了两组：`HDMI_*_P` (C3/G5/F1/E1) 与 `HDMI_*_P1` (K1/F5/E3/B3)。我们沿用参考工程的 B 口即可，A 口留作备用或做双屏。

### 4.2 音频：三条可用路径

| 路径 | 引脚 / 方式 | 评价 |
|---|---|---|
| **① 蜂鸣器** | **BUZZER = H11**（低电平响，SW5 拨下接通） | 最简，可发出节拍"滴"声。⚠️只有单音，听不了语音 |
| **② HDMI 音频** | 参考工程的 HDMI 核**自带音频输入端口**（`I_audio_left/right_data`, `I_audio_valid`） | ✅ **推荐。可直接从显示器喇叭出声，能播语音** |
| **③ WM8731 codec** | `aud_xck=E15`, `aud_bclk=F15`, `aud_daclrck=J16`, `aud_dacdat=G14`, `i2c_sclk=M10`, `i2c_dat=P11`, 功放使能 `keyon=A4` | ⚠️ 这些引脚**与 J1 扩展口共用**，且疑似需外接模块；与按压采集有引脚冲突风险 |

> **建议**：主用 **HDMI 音频**（基础要求 3 稳），节拍提示音可以**同时**走蜂鸣器 H11（冗余 + 现场更响）。

## 五、★ 片内 ADC 的引脚找到了

### 5.1 ADC 规格（`EG4S内部ADC使用指南.pdf` + `EG4S20数据手册.pdf`）

| 项 | 指标 |
|---|---|
| 类型 | **逐次逼近（SAR）** |
| 通道数 | **8 个模拟输入** |
| 分辨率 | **12 bit**（**有效精度 8 bit**） |
| 采样率 | **最高 1 MSPS**；时钟 **fmax = 16 MHz** |
| 输入范围 | **0.1×VREF ~ 0.9×VREF** |
| VREF | 0.5~1.0 × VDDA，建议取 1.0×VDDA |
| 工作电压 | VDDA = VDDD = **3.3V** |
| 关键约束 | 「8 个通道输入**和用户 IO 复用**……未使用的 ADC 通道管脚可以作为普通 IO 使用」<br>「使用 ADC 时，相关 BANK 的 **VCCIO 电压应不低于 ADC 模拟电源电压**」<br>「**尽量避免使用 ADC IO 相同 BANK 的数字 IO 以减小噪声**」 |
| 采样间隔 | 建议 SOC 间隔 <10µs（即采样率不低于 100 kHz）；若大间隔采样，需在 SOC 前 5 个时钟周期拉高一下 PD |

### 5.2 ADC 通道引脚（数据手册直接给出）

| 通道 | FPGA 引脚 | 是否引到扩展口 |
|---|---|---|
| **ADC_CH_0** | **N11** | 待核 |
| **ADC_CH_1** | **M10** | ✅ J1（P1IO[13]） |
| **ADC_CH_2** | **L10** | ✅ J1（P1IO[12]） |
| **ADC_CH_3** | **P11** | ✅ J1（P1IO[11]） |
| **ADC_CH_4** | **M12** | ✅ J2（脚 35，GPIOB_30） |
| **ADC_CH_5** | **N12** | ✅ J2（脚 37，GPIOB_32） |
| **ADC_CH_6** | **P12** | ✅ J2（脚 39，GPIOB_34） |
| **ADC_CH_7** | **R16** | ✅ J1（P1IO[32]） |
| ADC_VREF | VCCIO8（BANK8 电源） | — |

> **至少 7 个 ADC 通道引到了 J1/J2 扩展口，可以直接接杜邦线。**
> 注意：M10、P11、L10 同时也是 WM8731 的 I2C/时钟引脚——**如果走 HDMI 音频，就不冲突**。

### 5.3 对按压盒的意义（方案可以定了）

```
VCC3V3 ──[ 10k ]──┬──── FSR（力敏电阻）──── GND
                  │
          ADC_CH_x（M10/L10/P11/M12/N12/P12/R16 之一）
                  │
            接 J1 或 J2 扩展口
```

| 项 | 开关阵列方案 | **FSR + 片内 ADC（推荐）** |
|---|---|---|
| 机械件 | 4 个微动开关 + 长短挡片，**要反复试** | **只要弹簧 + 一块压板** |
| 深度分辨率 | 三档 | **连续**（有效 8 bit） |
| 额外芯片 | 无 | **无** |
| FPGA 侧 | 读 4 路电平 | **`EG_PHY_ADC` 时序状态机 + 标定表** |
| 引脚 | 4 个普通 IO | **1 个 ADC 通道引脚（扩展口已有）** |

**双轨保留**：若片内 ADC 实测有困难，退回 4 路数字输入（按键/拨码开关已足够）或在扩展口接外置 12 位并行 ADC（AD9224 / ADS807，配套 DAC9763，官方有例程 `28_adda_direct`）。

## 六、TF 卡与扩展口

### 6.1 TF 卡槽（**6 线全引出**；参考工程按 **SPI 模式** 用其中 4 线）

> ⚠️ **措辞更正（2026-09-16）**：本节原标题写作"板采用 **SD 模式**"，容易被误读成"必须写 SD 协议栈"。
> **准确说法是**：卡座按标准 SD 卡座布线、**6 根线全部引到 FPGA**，所以**两种模式都支持**。
> **参考工程用的是 SPI 模式**，只用其中 4 根。详见下方对照。

**开发板手册原文**（`_ref/手册摘录/board_manual.txt` 第 497~526 行）：

> 「TF卡(Secure Digital Memory Card)**有两种模式，一种是SD模式，一种是SPI模式**」

**同一批物理引脚，两套用途**（手册的引脚表两个名字都标了）：

| 引脚 | SD 模式的名字 | SPI 模式的名字 | 8 脚定义 |
|---|---|---|---|
| **A12** | SD_DAT3 | **CS**（片选） | 2 |
| **A13** | SD_CMD | **DI / MOSI** | 3 |
| **A14** | SD_CLK | **SCLK** | 5 |
| **B14** | SD_DAT0 | **DO / MISO** | 7 |
| A11 | SD_DAT2 | *rsv*（保留，不用） | 1 |
| B15 | SD_DAT1 | *rsv*（保留，不用） | 8 |

**模式怎么选——不需要跳线，卡自己认**：

> **CMD0（复位命令）发出时，如果 CS（DAT3）被拉低 → 卡进入 SPI 模式。**
> 卡上电后默认 SD 模式，靠协议切换，硬件不用动。

**两种模式对比**：

| | **SD 模式**（原生） | **SPI 模式**（参考工程用的） |
|---|---|---|
| 用几根线 | 6 根：CLK、CMD、DAT0~DAT3 | **4 根**：CLK、DI、DO、CS |
| 数据宽度 | 1 位 **或 4 位** | 只能 1 位 |
| 速度 | 50 MHz × 4 bit = **25 MB/s** | 25 MHz × 1 bit = **3.125 MB/s** |
| 协议复杂度 | **高**（CRC7/CRC16、R1/R1b/R2/R3/R6/R7 多种响应、双向 IO + 三态控制） | **低**（发字节/收字节，只有 R1） |
| 典型实现 | 要写完整 SD 协议栈 | **一个移位寄存器就够** |

**证据链——三条完全对得上**：

1. **板子手册**：两种模式的引脚名都标了 → 板子两种都支持
2. **参考工程的引脚约束**（`05_lab_ex/.../constraints_source/pin.adc`）：
   ```
   sd_dclk → A14    ✓ SD_CLK / SCLK
   sd_miso → B14    ✓ SD_DAT0 / DO
   sd_mosi → A13    ✓ SD_CMD / DI
   sd_ncs  → A12    ✓ SD_DAT3 / CS
   ```
   **正是 SPI 模式那 4 根，引脚号与手册一致**
3. **参考工程顶层端口命名**：`sd_ncs / sd_dclk / sd_mosi / sd_miso` —— 典型的 SPI 命名
   （SD 模式会叫 `sd_cmd` / `sd_dat0` / `sd_dat3`）
   且 `spi_master` 里 `CPOL=1, CPHA=1`，正是 SD 卡 SPI 模式的标准配置

> **结论：参考工程就是给这块板子写的，用的就是 SPI 模式。**

**要不要改用 SD 4-bit 模式？→ 不建议。**

| 理由 | 说明 |
|---|---|
| 1 | 要写完整 SD 协议栈（CRC7/CRC16、多种响应、4 位时序对齐） |
| 2 | CMD 和 DAT **都是双向**的，要处理三态输出使能，调试难度上一个台阶 |
| 3 | **有双缓冲，多出来的时间观众看不见**（切图时后台在读，显示的是当前这张） |
| 4 | W1 的目标是"能读出扇区"，SPI 模式照抄就能过；SD 模式从零写第一周很可能过不了 |

**SPI 模式的代价**：A11 / B15 空着（可作普通 IO）；速度是 SD 模式的 1/8（被双缓冲掩盖）。
**换来的是：代码直接搬，零风险。**

**提速路线（如果哪天真嫌慢）**：先试**提高 SPI 时钟**（25 MHz → 40 MHz，部分卡能跑），比换模式简单得多。**但别在赛前动。**

## 九、按压盒实现与数据通路

### 9.1 三条数据链路（先看全貌）

```
按压盒（机械）
   │
   ├─ 力敏电阻 FSR ──→ 分压出模拟电压 ──→ ADC 通道引脚 ──┐
   │                                                      │
   └─（备选）微动开关 ──→ 数字电平 ──→ 普通 IO ───────────┤
                                                          ↓
                                        ┌─────────────────────────────┐
                                        │  FPGA（EG4S20BG256）        │
                                        │                             │
                                        │  adc_ctrl  ← EG_PHY_ADC 原语 │
                                        │      ↓ 12 位读数             │
                                        │  peak_detect  峰值检测       │
                                        │      ↓ 每次按压的深度值       │
                                        │  rate_judge   间隔 → 频率     │
                                        │      ↓                      │
                                        │  layer_mixer ──→ HDMI 输出   │
                                        └─────────────────────────────┘
```

**模拟量走片内 ADC，数字量走普通 IO，两条路的上层逻辑完全一样。**

### 9.2 按压盒机械结构

```
              ┌───────────────────┐   ← 手掌按压面：圆盘，直径约 12 cm
              │   压板（亚克力 5mm）│      模拟胸廓受力面
              └─────────┬─────────┘
                        │
        ┌───────────────┴───────────────┐
        │      弹簧 ×4（四角布置）        │   ← 提供回弹，形成 5~7cm 行程
        └───────────────┬───────────────┘
                        │
              ┌─────────┴─────────┐
              │   底板（亚克力）    │
              │   ┌───────────┐   │
              │   │    FSR    │   │   ← 贴在底板中央，压板压下时受力
              │   └───────────┘   │
              └───────────────────┘
```

**关键尺寸与选型**

| 项 | 建议值 | 说明 |
|---|---|---|
| 最大行程 | **≥ 7 cm** | 要覆盖"5–6cm 达标"区间，并能压到"过深" |
| 压板直径 | 约 12 cm | 手掌大小 |
| 弹簧 | **4 根，压到 6cm 时总力约 15–25 kg** | 太软一压到底分不出档位，太硬按不动 |
| 导向 | **4 根 M4 螺杆穿过压板四角**（最省），或抽屉滑轨 | 防止压板歪斜导致 FSR 受力不均 |
| FSR | 量程覆盖上述压力，**受力面积与底板贴合** | |

> **为什么不追求真实 CPR 的 50kg 力**：训练盒的目的是练**节奏与幅度**，不是练力气。15–25kg 的阻力已经能形成清晰的手感与行程。

### 9.3 传感器电路（主方案：FSR）

```
        +3.3V（从 J1/J2 扩展口取）
          │
        ┌─┴─┐
        │10k│  分压电阻
        └─┬─┘
          ├──────────────→ 接 ADC 通道引脚
          │                 （M10 / L10 / P11 / M12 / N12 / P12 / R16）
        ┌─┴─┐
        │FSR│  力敏电阻：受压 → 阻值下降 → 该点电压升高
        └─┬─┘
          │
         GND（从 J1/J2 扩展口取）
```

**读数方向**：压得越深 → FSR 阻值越小 → 分压点电压越高 → ADC 读数越大。

**⚠️ 接线红线**
- 只能接 **3.3V**。手册明确警告：「扩展口 IO 与 FPGA 直连，**如要接 5V 设备，需要接电平转换芯片**，以免烧坏 FPGA」
- J1/J2 上**同时有 5V 和 3.3V**，别接错
- 尽量避免使用与 ADC 同 BANK（BANK2）的数字 IO，以减小噪声（手册建议）

### 9.4 备选方案：微动开关阵列（纯数字，零标定）

如果 FSR 标定不顺，退回这条路：

```
  压板下压 ──→ 滑杆上的两条长度不同的挡片
                    │
        ┌───────────┴───────────┐
        │                       │
   开关1 @5cm 位置          开关2 @6cm 位置
   （挡片长：5→7cm）        （挡片长：6→7cm）
```

| 按压深度 | 挡片压住谁 | 判定 |
|---|---|---|
| < 5 cm | 都没压住 | **太浅** |
| 5–6 cm | 只有挡片 1 | **正确** |
| ≥ 6 cm | 挡片 1 + 挡片 2 | **过深** |

开关一端接普通 IO（内部上拉），一端接 GND。
**优点**：零标定、零模拟电路。**缺点**：机械精度要试，且只能分三档。

### 9.5 FPGA 侧：怎么读片内 ADC

**原语**（TD 官方模板 `EG4_Primitive/eg4_advanced.v`）

```verilog
EG_PHY_ADC #(
  .CH0 ("DISABLE"), .CH1 ("DISABLE"), .CH2 ("DISABLE"), .CH3 ("DISABLE"),
  .CH4 ("DISABLE"), .CH5 ("DISABLE"), .CH6 ("DISABLE"), .CH7 ("DISABLE"),
  .VREF("DISABLE")
) u_adc (
  .clk  (adc_clk),   // ≤ 16 MHz
  .pd   (adc_pd),    // power down：1'b0 = 正常工作
  .s    (adc_ch),    // 3 位通道选择
  .soc  (adc_soc),   // 启动转换，高有效
  .eoc  (adc_eoc),   // 转换结束，高有效
  .dout (adc_dout)   // 12 位结果
);
```

**控制时序（状态机）**

| 状态 | 动作 |
|---|---|
| `IDLE` | 等待采样周期到（我们约 1 ms 一次，即 1 kHz） |
| `PRE` | **拉高 `pd` 保持 5 个 `clk`，再拉低** ← 见下方注意事项 |
| `SOC` | 拉高 `soc` 若干 `clk` |
| `WAIT` | 等 `eoc` 变高 |
| `LATCH` | 读走 `dout[11:0]`，回到 `IDLE` |

> **⚠️ 官方文档的关键注意事项**：
> 「建议 SOC 采样间隔要小于 10µs，即采样频率不要低于 100kHz；**若需要大间隔的采样，需要在 SOC 到来 5 个时钟周期前拉高一下 PD 脚之后再进行采样**。」
>
> 我们要的是 1 kHz（远大于 10µs 间隔），所以**必须走"先 PD 复位再采样"这条路**。这一条如果漏掉，读数会不对——是很容易踩的坑。

**为什么采样率可以低**：CPR 按压只有约 2 Hz。1 kHz 采样等于每次按压采 500 个点，**绰绰有余**。

### 9.6 深度怎么算出来（关键，且很简单）

#### 第一步：不用算物理量，直接标定两个门限

不需要知道 FSR 的阻值、压力、弹簧刚度。**直接在压板上做两次标定**：

| 标定 | 做法 | 得到 |
|---|---|---|
| 标定 5 cm | 压板上垫 5cm 垫块，压实，记录 ADC 峰值 | **`T_low`** |
| 标定 6 cm | 换成 6cm 垫块，压实，记录 ADC 峰值 | **`T_high`** |

判定：

| ADC 峰值 | 与门限比较 | 判定 |
|---|---|---|
| < `T_low` | 没压到 5cm | **太浅**（黄） |
| `T_low` ~ `T_high` | 落在 5–6cm 区间 | **正确**（绿） |
| ≥ `T_high` | 超过 6cm | **过深**（红） |

**只需要两个标定值，写进两个寄存器即可。** 不需要查找表，不需要除法。

#### 第二步：峰值检测（每次按压取最大值）

```
双门限施密特 + 峰值跟踪：

  ADC 值 > T_low            → 进入"按压中"，开始跟踪峰值
  按压中，ADC 继续升高      → 更新峰值
  ADC 回落到峰值的 70% 以下 → 判定这次按压结束，输出峰值 → 送评级
```

双门限（`T_low` 进、`T_low×0.7` 出）能避免阈值附近的抖动造成重复计数。

#### 第三步：频率测量

**用"进入按压中"的时刻（上升沿）作为一次按压事件**，测相邻事件的时钟间隔：

| 相邻间隔 | 对应频率 | 判定 |
|---|---|---|
| < 500 ms | > 120 次/分 | **偏快**（黄） |
| 500–600 ms | 100–120 次/分 | **正确**（绿） |
| > 600 ms | < 100 次/分 | **偏慢**（黄） |

**不做除法**——直接判区间。要显示"112 次/分"就查一张 16 项 ROM 表。

### 9.7 接线清单

| 从哪 | 到哪 | 线 |
|---|---|---|
| J1 或 J2 的 **3.3V** | 分压电阻上端 | 1 |
| J1 或 J2 的 **GND** | FSR 下端 | 1 |
| 分压点 | **ADC 通道引脚**（如 J1 的 M10） | 1 |
| （备选）开关 1 | J1/J2 任一普通 IO | 1 |
| （备选）开关 2 | J1/J2 任一普通 IO | 1 |

**一共 3 根杜邦线就能跑起来。**

### 9.8 调试顺序（建议）

1. **先接电位器**代替 FSR，转旋钮看屏幕上 ADC 数值是否从 0 到满量程线性变化 → **验证 ADC 通路**
2. 换上 FSR，手压看数值是否随力度上升 → **验证传感器**
3. 垫块标定 `T_low` / `T_high` → **得到两个门限**
4. 接上弹簧与压板，连续按压看评级是否跟手 → **联调**

> **第 1 步单独拿出来先做**——它把"ADC 能不能用"这个唯一的未知项一次性解决掉，与机械件无关。
