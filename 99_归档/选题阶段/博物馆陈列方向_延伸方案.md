# 博物馆陈列方向的延伸

> 之前的"声画长卷"只做到"把长卷播出来"，切口太浅。本文根据文博行业的**官方调研结论**重新定位，并延伸出 5 个子方向。
> 结论：**核心从"能播长卷"改为"能让观众看清细节"**。

---

## 一、先纠正一个判断：博物馆缺的不是"屏"

行业自己已经把问题说清楚了。两篇调研材料，结论高度一致：

### 1.1 《中国文物报》2026-08-27《汉画像石与石窟寺石刻保护的数字化反思》

作者孙越（中国科学技术大学），文中对全行业的诊断：

> 「当前行业内对上述政策的讨论多聚焦于**硬件采购规模、文物数字化采集数量**等表层维度。」
> 「当前存在两个问题。一是「**重硬件、轻内容**」。笔者调研中看到，**有的基层馆花重金买了 VR 设备，却因缺乏适配内容长期闲置**。二是「**娱乐化稀释**」。一些"沉浸式体验"用声光电掩盖了文物本身的信息，**观众记住了互动游戏闯关，却记不住画像石里的历史故事**。」
> 「**中小博物馆藏品少、空间小、人才缺，数字化场景的轻量化构建是一条出路。**」

来源：[中国文物报数字报 2026-08-27 第七版](http://www.zhongguowenwubao.com/portal/DigitPager/paperDetail/publishdate/2026-08-27/paperId/22859/id/112716)

### 1.2 九三学社大同市委会《运用数字技术提升全市文物保护与展示利用高质量发展》（2025-03-28）

大同有 30 处国家级重点文保单位、63 处省级、35 座对外开放博物馆。调研结论：

> 「**展示形式单一**。目前我市的文物数字化展示**主要以图片、文字、视频等传统形式为主，缺乏创新性和互动性**。」
> 「**后续维护资金缺乏**。文物数字化成果需要定期进行维护和更新……由于缺乏后续维护资金，**一些已经完成的数字化项目逐渐变得陈旧、过时，无法发挥应有的作用**。」
> 「内容深度挖掘不足」「复合型人才匮乏」

来源：[政协大同市委员会](http://dtszx.gov.cn/wylz/sglz/art/2025/art_e2be2622720349bd965ee2a654a4af65.html)

### 1.3 政策窗口

| 文件 | 相关表述 |
|---|---|
| 《十五五规划纲要》第34~36章 | 「**提升智慧博物馆**、智慧图书馆、公共文化云服务效能」「推进文化和科技融合，**推动文化建设数智化赋能、信息化转型**」 |
| 《国家文物事业发展"十五五"规划》（2026年7月） | 「**整合文物领域现有数据平台和多元异构数据**」；预期性指标：**博物馆年举办原创临时陈列展览数量 1.4万 → 1.5万个** |
| 《关于推进实施国家文化数字化战略的意见》 | 「大力发展线上线下一体化、**在线在场相结合**的数字化文化新体验」 |

**结论**：行业不缺数据（已采集）、不缺预算意识（愿买设备），缺的是**"数据能直接用上、且养得起"的轻量终端**。这正是无操作系统、低功耗、免维护、内容可换的 FPGA 方案的位置。

## 二、三条延伸线

把行业痛点直接翻译成技术需求：

| 行业原话 | 延伸线 | 技术动作 |
|---|---|---|
| 「展示形式单一，以图片、文字、视频为主」「观众很难看清文物细节」 | **看清** | 超高分辨率文物图的**实时无级缩放与平移** |
| 「内容深度挖掘不足」「娱乐化稀释」 | **看懂** | **多图层精准阐释**：原件 / 线图 / 拓片 / 释文，可叠加可对比 |
| 「重硬件轻内容」「维护资金缺乏，成果逐渐陈旧」 | **换得起** | **内容与硬件解耦**：换展换一张 SD 卡 |

## 三、五个延伸子方向

### A. 文物细节实时阅览终端（数字放大镜）★ 核心延伸

| | |
|---|---|
| **痛点** | 展示形式单一；铭文、纹饰、笔触肉眼看不清 |
| **形态** | 主视图显示整件文物，一个可移动的放大窗跟随按键移动到任意位置，倍率连续可调 |
| **FPGA 真活** | **超高分辨率图像的实时无级缩放**；**主视图与放大窗双视图并行渲染**（位置/倍率独立）；多层合成 |
| **演示动作** | 现场把放大窗移到器底铭文，放大 12 倍，铸痕与笔画转折逐层显出 |
| **区分度** | 视频播放器**原理上做不到**——任意位置、任意倍率，没有对应视频 |

### B. 文物对比阅览终端（跨区域 / 同母题）

| | |
|---|---|
| **痛点原文** | 「想**跨区域比对同一神兽母题的雕刻技法**，目前很难通过现有公开数据库完成系统的类型学分析」 |
| **形态** | 左右分屏，两件文物各自独立缩放平移，可锁定同步移动；也可原件与线图/拓片透明比对 |
| **FPGA 真活** | 双通道独立图像变换 + 同步锁定 + 透明混合 |

**这个方向在文博研究上是真需求**（类型学比对），而且技术上比 A 更难一点，答辩更有话讲。

### C. 石刻劣化时间序列阅览终端

| | |
|---|---|
| **痛点原文** | 「高清摄影和微痕扫描多属于"定期体检"式的快照……**能看清"现在坏了多少"，却很难说清"每年坏了多少"**」 |
| **形态** | 同一位置不同年份的图像按时间轴切换/滑动比对，劣化区域高亮叠加 |
| **FPGA 真活** | 多时期图像的对齐叠加、差值高亮、时间轴滑杆 |

### D. 长卷数字展卷终端（原方案保留）

| | |
|---|---|
| **痛点** | 书画长卷真迹受光照限制，极少展出；展签信息量有限 |
| **形态** | 长卷实时展开，可随时停下放大局部看笔触，题跋与印章标注浮现，旁白同步 |
| **FPGA 真活** | 长幅图像的实时平移 + 局部放大 + 标注图层 + 字库渲染 |
| **相对位置** | A 的"横向版"，技术复用度高，可作为 A 的一个模式 |

### E. 临展轻量化换展终端

| | |
|---|---|
| **痛点** | 十五五规划把原创临展数量指标从 1.4 万提到 1.5 万；基层馆「维护资金缺乏，项目逐渐陈旧」 |
| **形态** | 同一台硬件，换展只换 SD 卡；事件表驱动内容排期 |
| **FPGA 真活** | **事件表引擎**：内容与硬件解耦 |
| **相对位置** | E 不是一个独立方向，而是 **A/B/C/D 共同的产品形态属性**——建议作为"产品能力"写进方案，而不是单独做 |

## 四、设计理念（差异化的一句话）

行业自己批评「**娱乐化稀释**」——「用声光电掩盖了文物本身的信息」。

所以本方案应当**反其道而行：做减法**。

> **不追求声光电的炫目，而是把观众看不清的东西——铭文、纹饰、笔触、拓片——用最清晰的方式呈现出来。**
> 一块屏、几个按键、没有动画特效，只有文物本身。

这句话写在答辩 PPT 的第一页，比任何技术指标都更能让文博背景的评委认同。

## 五、技术点与赛题对应

| 赛题要求 | 本方案对应 |
|---|---|
| 多幅图像播放（≥4幅） | 多件文物切换；同一文物的原件/线图/拓片多层 |
| 透明叠加 / 透明色处理 | 释文、线图、拓片与底图的透明混合；双图比对 |
| 按键交互（≥2按键） | 移动放大窗、调节倍率、切换图层、切换文物 |
| 图片平移 / 局部放大 | **核心能力**（A 的主体） |
| 音频播放 | 旁白讲解 |
| 音频可视化 | ⚠️ 未实现前按 **4/5** 口径 |

**功能点覆盖**：**5 项全覆盖**，且"平移/局部放大"从"扩展项"变成"主功能"——这是前几版博物馆方案没有做到的。

## 七、作品简介（上限 500 字，**含换行符**，已逐字核算）

### ★ A_推荐版 —— 466 字（含换行）/ 464 字（去空白）

```
《国家文物事业发展“十五五”规划》要求提升智慧博物馆服务效能，并把“博物馆年举办原创临时陈列展览数量”从1.4万个提升至1.5万个。但行业调研反复指出同一个问题：重硬件、轻内容。有的基层馆花重金购置VR设备，却因缺乏适配内容长期闲置；不少文物数字化成果采完即存，展示仍以图片、文字、视频为主，观众很难真正看清一件文物的细节。中小博物馆藏品少、空间小、人才缺，数字化场景的轻量化构建是一条出路。
```

## 八、红线自查

| 红线 | 做法 | 结论 |
|---|---|---|
| 不得带处理器 | 全设计仅 EG4S20 | ✅ |
| 不得算法预处理 | 缩放、平移、图层混合**全部逐帧实时计算** | ✅ |
| 不得预先渲染 | SD 卡里只有**高清文物原始图像**（等同"文物照片"）与事件表，**没有任何一段预制视频/动画** | ✅ |
| 素材边界 | 文物高清图是**采集素材**（本就存在），不是"FPGA 该算出的中间结果"；线图/拓片是**既有学术资料**，不是我们算的 | ✅ |

> **本方向在合规上特别干净**：因为"预先渲染"这条路根本走不通——观众要放大到哪、放大多少倍，是事先不知道的，只能实时算。
