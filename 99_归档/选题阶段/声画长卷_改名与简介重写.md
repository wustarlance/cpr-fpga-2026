# 声画长卷方向：改名 + 简介重写 + 内容拓展

> 三件事：**改名称**、**重写简介**（对齐基础 4 条 + 扩展 5 条）、**拓展内容**（把展陈场景真正跑起来所需的能力补齐）。

## 一、改名

### 原名的问题

「**声画长卷 · 交互式 · 数字展陈终端**」——13 字，五个概念堆在一起：

| 词 | 问题 |
|---|---|
| **交互式** | 凡是"终端"都带交互，属于冗余限定 |
| **数字** | 「展陈终端」本身就意味着数字，重复 |
| **声画** | 保留——这是本作品最独特的记忆点 |
| **长卷** | 保留——这是形态的核心 |
| **展陈终端** | 保留——这是场景 |

去掉两个冗余词，**13 字 → 8 字**，反而更好记。

> **海报主标题建议**：`十二米长卷，一屏展开`

## 二、内容拓展

原方案只有"长卷平移 + 局部放大 + 字幕 + 旁白"。要真正在展厅里跑起来，还缺几样：

| 新增能力 | 为什么需要 | 对应要求 |
|---|---|---|
| **自动巡航 + 手动接管** | **展厅经常无人**。长卷自动缓缓展开做背景；观众一按键就接管，松手后回到巡航。没有这一条，屏会长时间静止 | 交互控制 |
| **题跋 / 钤印 / 释文多层** | 书画长卷的价值很大一部分在题跋与钤印上，原来只有底图 | **扩展①** |
| **事件表驱动的展线** | 从"一件长卷"拓展到"**一条展线**"：多卷轮播、每卷多段，各自带字幕与旁白 | 扩展② |
| **音频可视化** | 旁白与背景音乐生成频谱，与画面同步 | **扩展⑤** |
| **亮度 / 对比度 + OSD** | 展厅光照差异极大；书画展陈常处于低照度环境，更需要调节 | **扩展④** |

补齐之后：**基础 4 条 + 扩展 5 条全部覆盖**，而且"自动巡航"解决了"展厅无人时屏在干什么"这个实际问题。

## 三、重写后的作品简介

### ★ A_逐条对应版 —— 486 字（含换行）/ 484 字（去空白）

> 结构：**政策与痛点 → FPGA 优势 + 基础要求 → 扩展①~⑤逐条**。评委对照评分表，一条不落。

```
《国家文物事业发展“十五五”规划》要求提升智慧博物馆服务效能，并提出加强馆藏文物数字化保护、深化数字资源开放共享；全国备案博物馆已达7188家，2025年接待观众超15.6亿人次。但书画长卷受光照限制极少展出，观众隔着展柜也看不清笔触；而现有数字展陈多依赖工控机与投影，成本高、启动慢、需专人维护，中小博物馆用不起。
本作品是一台声画长卷展陈终端，以国产安路EG4S20为核心，全部算法与控制逻辑在FPGA内自主编程实现，无任何处理器。终端扫描SD卡图像资源、解析BMP文件并写入SDRAM帧缓存，经HDMI同时输出视频与音频。长卷远超屏幕宽度，平移位置由像素时钟直接驱动，每帧位移严格相等，可自动缓缓展开，观众按键即可接管并放大到笔触级别；画面上分层叠加题跋、钤印与释文，底部导览文字由片内点阵字库实时渲染并平滑滚动。
扩展功能逐条实现：①多图层叠加与平滑滚动字幕；②卷目间淡入淡出与滑动转场；③不同分辨率长卷自适应缩放；④按键调节亮度对比度并显示档位，适应展厅光照差异；⑤旁白与背景音乐以多段滤波器组生成频谱。内容由事件表驱动，换展只需替换SD卡，无需重新综合与烧写。
```

### C_技术机制版 —— 389 字（含换行）/ 387 字（去空白）

> 面向技术评委，把"硬件流水线如何工作"讲透。

```
本作品是一台基于安路EG4S20的声画长卷展陈终端，把远超屏幕宽度的横向长卷，做成可以在展厅里自动展开、随时停下来放大看细节的一块屏。
终端扫描SD卡图像资源、解析BMP文件并写入SDRAM帧缓存，经HDMI同时输出视频与音频。FPGA在像素域实时完成三件事：一是长卷平移，位置由像素时钟直接驱动、每帧位移严格相等，无软件调度抖动；二是多图层合成，画面层、题跋钤印层与释文层按透明色键控叠加；三是局部放大与自适应缩放，任意倍率任意位置都逐帧重算。导览文字由片内点阵字库实时渲染并平滑滚动。
扩展功能逐条实现：①图层叠加与平滑滚动字幕；②卷目间淡入淡出与滑动转场；③不同分辨率长卷自适应缩放；④按键调节亮度对比度并显示档位；⑤多段滤波器组生成音频频谱。内容由事件表驱动，全部算法与控制逻辑在FPGA内自主编程实现，无任何处理器；换展只需替换SD卡，上电即出画面，功耗远低于工控机。
```
