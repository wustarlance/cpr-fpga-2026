# 去掉实时绘制：把难度降到最低

> 结论：**可以砍，而且砍完之后反而更贴合赛题本意。**
> 赛题的硬性要求是「多幅图像播放 + 透明叠加 / 透明色处理 + 按键交互」——**这三条本来就不需要实时绘制**。

---

## 一、把"实时"按难度分档

| 档 | 操作 | 实现方式 | 成本 |
|---|---|---|---|
| **A 免费** | 透明色键控叠加 | 1 个比较器 + 1 个多路选择器 | 几乎为零 |
| | 图层开 / 关 | 多路选择器 | 几乎为零 |
| | 画面平移 | 地址加偏移 | 几乎为零 |
| | 滑入转场 | 计数器 + 地址偏移 | 几乎为零 |
| | 进度条 / 状态条 | 计数器 + 比较器 → 矩形填充 | 几乎为零 |
| | 闪烁提示 | 计数器取高位 | 几乎为零 |
| **B 便宜** | **最近邻缩放（含无级）** | **一个相位累加器**（加法器 + 比较器） | 极低 |
| | **放大窗 / 画中画** | 同一图像读两次，第二次用不同地址与步进 | 极低 |
| | **双图对比（左右分屏）** | 两套地址，按 x 坐标选择 | 极低 |
| **C 中等** | 淡入淡出 | alpha 线性渐变 + 2 个乘法（或移位近似） | 中 |
| | 双线性插值缩放 | 行缓存 + 4 点插值 | 中高 |
| **D 费劲（建议砍）** | 实时曲线绘制 | 数据缓存 + 坐标变换 + 逐列画线 | 高 |
| | 仪表指针 / 圆弧刻度 | sin / cos 查找表 + 圆弧判定 | 高 |
| | 环形图 / 饼图 | 距离与角度判定，需要开方 | 高 |
| | 大图无级平移缩放（流程图 / 地图） | 分块缓存管理 + 抗锯齿 | 高 |

**关键认识**：I 档里"看起来最唬人"的**放大窗**其实只要一个相位累加器；D 档里"看起来最朴素"的**仪表指针**反而要算三角函数。

---

## 二、推荐方案：只做 A 档 + B 档

砍完之后剩下的能力：

| 功能 | 档 | 覆盖赛题 |
|---|---|---|
| 多幅图像播放（SD 卡读取、双缓冲） | 基础设施 | ✅ 硬性要求 |
| 双层合成 + 透明色键控 | A | ✅ 硬性要求 |
| ≥2 按键 | A | ✅ 硬性要求 |
| 画面平移 | A | ✅ 扩展项 |
| **放大窗（局部放大）** | B | ✅ 扩展项 |
| 滑入 / 淡入转场 | A / C | 加分 |
| 音频播放（I2S，参考工程现成） | — | 加分 |

**没有曲线、没有仪表、没有图表、没有大图漫游。**

> **一个便宜的亮点**：**放大窗（画中画）** —— 屏幕上一个小方框跟随按键移动，框内实时显示该区域的放大画面。
> 实现上只是"把同一张图读两次"，但演示效果非常像"实时图像处理"。**性价比最高的一处**。

## 三、场景也要跟着换：工业方向选"图片为主"的

既然不做实时图形，工业方向的场景就应该选**以图片为主体**的。最合适的是：

### 工位电子作业指导终端（e-SOP）

| 项 | 内容 |
|---|---|
| **一句话** | **给工位换一块屏：换型号时，屏幕上的作业指导跟着变；工人按键就能放大看关键部位。** |
| **政策抓手** | 工信部「十五五」新型工业化：推出**轻量化、低成本、易部署**的行业解决方案；开发更多「**小快轻准**」数字化转型产品 |
| **用户** | 产线工人、班组长、工艺工程师 |
| **场所** | 工位上方或侧方，悬挂 / 支架安装 |
| **现在怎么做** | 纸质 SOP 挂在工位，换型号就换纸、容易用错旧版本；升级方案是工位一体机，要采购、布线、专人维护 |
| **痛点** | 多品种小批量生产下**换型频繁**，纸质文件跟不上；一体机对中小工厂太重 |

**画面里全是图片**（不是算出来的），正好对应 A/B 档能力：

| 功能 | 对应 |
|---|---|
| 按键切换上一步 / 下一步 | 多幅图像播放 |
| 按键**开关标注层**（公差、方向、力矩提示） | **透明色键控叠加** |
| 按键**开关放大窗**，移动方框看关键部位 | **局部放大** |
| 按键平移画面 | 平移 |
| 换型 | **换一张 SD 卡** |

**演示动作**：切换工位型号 → 步骤图整体换掉；按【放大】→ 放大窗里的螺栓朝向看得清清楚楚；按【标注】→ 力矩与方向提示浮上来。

**为什么这个场景好**：
1. 全程只需要"读图 + 合成 + 地址变换"，**硬件成本极低**
2. "换型换卡"是工厂真实痛点，不是硬凑
3. 无操作系统、无风扇、上电即亮，适合粉尘油雾车间
4. 政策原话直接对应（轻量化、低成本、易部署、小快轻准）

## 四、关于"素材都是预先做好的图"——合规口径

既然不做实时绘制，所有画面都是**预先准备的图片**。这一点要能回答：

> **赛题约束的是"设备上不得带有额外处理器"，不是"素材不能用电脑做"。**
> 任何一台多媒体播放设备（包括商用广告机、电子看板）的素材都是在电脑上制作的，这属于**素材准备**，不属于"算法预处理"。

**建议的口径**：
> 「SD 卡里是美术人员制作的作业步骤图与标注层，FPGA 负责读取、透明色键控合成、平移与放大。**设备本身不含任何处理器。**」

**一个稳妥的小加分**：标注层里的文字（如"力矩 25N·m"）如果由**片内点阵字库实时渲染**，而不是做成图片，既省素材准备时间，又能主动说一句"文字是实时渲染的"。**这一步成本很低，建议保留。**

## 七、红线自查

| 红线 | 做法 | 结论 |
|---|---|---|
| 不得带处理器 | 全设计仅 EG4S20 | ✅ |
