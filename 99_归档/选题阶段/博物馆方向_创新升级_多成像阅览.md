# 博物馆方向 · 创新升级：从「看清细节」到「看见过程」

> 在《博物馆陈列方向_延伸方案.md》的基础上加创新点。技术底座不变，**只加一层能力，但改变了作品的立意**。
> 结论：主推**创新点 ① 多成像模式实时切换与融合**。

---

## 一、创新思路

上一版的核心是"**看清细节**"——放大看铭文、笔触、纹饰。这是"看清**画了什么**"。

加一层之后，核心变成"**看见过程**"——看见起稿线、涂改痕迹、被覆盖的内容。这是"看见**画过什么**"。

**这不是功能叠加，是立意升级**：博物馆陈列通常展示"成品"，而本作品让观众看到**一件文物从试探、修改到定稿的旅程**。

---

## 二、文博技术依据（这是真实的前沿技术，不是噱头）

### 2.1 红外反射成像能看见"色层之下的秘密"

《绘画的秘密》相关报道（2026-06）记载了几个经典案例：

- **拉斐尔《圣母的婚礼》**：红外反射检测下，画中人物与背景中宏伟神殿的**起稿线条完全显现**，连十六边形神殿的底层素描、与地面透视网格的连接方式都清晰可见
- **《圣母子与羔羊》**：20 世纪 90 年代初 X 射线分析发现，画面最初并非羔羊，**而是一只黑猫**（以达·芬奇《圣母与猫》为蓝本的草图），因订购者喜好被完全覆盖
- **戈雅**在西班牙政权更迭后，彻底抹掉了约瑟夫·波拿巴的肖像；**安格尔**在拿破仑垮台后用帷幔遮住了画中拿破仑之子的身影

原文的关键表述：
> 「许多经典画作的颜料之下，都藏着艺术家最早的构图底稿。**这些线条在肉眼下无迹可寻，却能在红外反射成像中清晰显现。**」

技术脉络：20 世纪初博物馆开始用 **X 光**研究绘画 → 后来出现**红外反射成像技术、紫外线拍摄技术** → 更复杂的**光谱摄影、发射成像** → 数字化。

来源：[《色层之下，藏着怎样的秘密？》2026-06-26](https://www.sohu.com/a/1042228216_122036061)

### 2.2 可以直接用作作品精神内核的一句话

> 「**再伟大的艺术家，也不是落笔即完美。创作本就是一场不断试探、修改、推翻与重建的旅程。**」
> ——彼得罗·C. 马拉尼（Pietro C. Marani）

这句建议放在答辩 PPT 第一页。它把技术讲成了故事。

### 2.3 龙门石窟的数字复位（创新点②的依据）

中国文物报 2026-07-25 报道龙门石窟研究院的实践：

- 龙门石窟有 **2345 个编号窟龛、近 11 万尊造像、2800 余处碑刻题记**
- 清末民初遭大规模盗凿，**近 10 个国家 40 余家博物馆及私人藏家**收藏有龙门造像
- 数字复位技术链：高精度采集 → **点云原位配准（Open3D + ICP 迭代最近点算法）** → 数字模型重建 → 3D 打印
- 量化指标：**配对成功率**与**点对距离均方差**
- 意义：「让造像残件原位研究**从经验判断走向数据实证**」

来源：[中国文物报 2026-07-25 第三版](http://www.zhongguowenwubao.com/portal/DigitPager/paperDetail/publishdate/2026-07-25/paperId/22764/id/112379)

## 三、三个创新点

### ① 多成像模式实时切换与融合 ★ 主推

| | |
|---|---|
| **是什么** | 同一件文物，从 SD 卡读取多组成像数据（可见光 / 红外反射 / 紫外荧光 / 线描拓片），观众按键即可在模式间连续切换 |
| **三种观看方式** | ① 单模式全屏；② 双模式**并排比对**；③ 双模式**透明融合**（混合系数连续可调，从纯 A 平滑过渡到纯 B） |
| **观众看到什么** | 起稿线、涂改痕迹、被覆盖的内容、褪色的字迹、肉眼不可见的病害 |
| **新增技术能力** | **多通道图像实时配准**（不同成像模式必须严格对齐）+ **加权融合** + **伪彩映射**（单通道数据映射到可比对的色彩空间） |
| **为什么必须是实时** | 融合系数、缩放、平移可以连续变化，**不可能为每一种组合预渲染视频** |
| **演示动作** | 按键让画面"沉入红外"，平静的表面下浮出密密麻麻的起稿线；再按键，分界滑杆一分为二，左边是今天的样子、右边是画家最初的想法 |

**这是把"文物无损检测"的专业方法，做成了观众可以亲手操作的展项。** 文博背景的评委会立刻认出来这是什么。

---

### ② 残块拼合演示（数字缀合的 2D 简化版）

| | |
|---|---|
| **是什么** | 屏幕上散落着几块残片，观众用按键移动并**旋转**它们，拼回画面中的原位 |
| **反馈** | 实时显示重叠区域的对齐程度（简化的匹配度指示） |
| **新增技术能力** | **图像旋转**（几何变换的新维度，需要反向映射 + 三角函数查找表）+ 实时差值统计 |
| **诚实说明** | 这是**演示与教育**用途，**不是科研级配准**。真正的点云 ICP 配准与均方差判据属于专业软件，本终端不做 |
| **演示效果** | 极强——观众亲手让一件"身首分离"的造像重新合璧 |

> ⚠️ **风险提示**：旋转需要每像素做坐标变换，是本方案中**资源压力最大**的一项。建议放在**第二阶段**做，不要放进最小可行版本。

---

### ③ 劣化时间轴滑动对比

| | |
|---|---|
| **是什么** | 同一位置不同年份的图像，用一条可滑动的分界线实时对比；或叠加差值高亮，把新出现的劣化区域标出来 |
| **依据原文** | 「高清摄影和微痕扫描多属于"定期体检"式的快照……**能看清"现在坏了多少"，却很难说清"每年坏了多少"**」 |
| **新增技术能力** | 分界线裁剪 + 差值增强 |
| **实现成本** | 低（复用现有的双图叠加与分屏逻辑） |

## 四、技术实现：复用为主，新增有限

现有引擎（《延伸方案》里的双视图 + 多图层）**大部分可以直接复用**：

| 能力 | 状态 |
|---|---|
| 图像无级缩放 / 平移 | 已有（核心） |
| 双视图并行渲染 | 已有（创新点①的"并排比对"直接用） |
| 多图层透明合成 | 已有（创新点①的"融合"直接用） |
| 点阵字库实时缩放 | 已有 |
| **多通道配准偏移** | **新增（小）**——每通道一组 x/y 偏移寄存器 |
| **融合系数连续可调** | **新增（小）**——一个按键步进的权重寄存器 |
| **伪彩映射** | **新增（中）**——查表式色带映射 |
| **图像旋转** | **新增（大）**——对应创新点②，建议二阶段 |
| **分界线裁剪 / 差值** | **新增（小）**——对应创新点③ |

**结论**：创新点 ① **只增加两级寄存器加一张色带查找表**，就能把作品从"高清阅览器"变成"多成像比对仪"。这是投入产出比最高的一处创新。

## 五、素材获取（本方案最大的实际风险，建议第一周解决）

创新点 ① 需要**同一件文物的多组成像数据**。按可靠性排序：

1. **真实的公开多光谱/IRR 数据** —— 最理想。可从学术论文附图、博物馆公开数据、开放文物数据集中寻找（**优先选这类**）
2. **与本地博物馆或高校文博专业合作获取** —— 若能拿到一组真实数据，方案的含金量立刻不同
3. **公开报道中的经典案例图** —— 如上述拉斐尔、戈雅等案例
4. **自制示意数据** —— 用一幅高清画作 + 手工描摹的"起稿线"合成演示对。**若采用这条路，必须在材料中明确标注为"示意数据"，不得声称是真实红外成像结果**

> ⚠️ **红线提醒**：绝对不要用"生成式 AI 编造"的成像结果并声称是真实检测数据。文博领域对"算法衍生作品冒充客观记录"有明确批评（见《中国文物报》关于"数字拓片"的讨论）。**诚实标注演示数据的性质**，反而是专业性的体现。

## 七、作品简介（上限 500 字，**含换行符**，已逐字核算）

### ★ A_推荐版 —— 466 字（含换行）/ 464 字（去空白）

```
《国家文物事业发展“十五五”规划》要求提升智慧博物馆服务效能。但文博行业调研反复指出同一个问题：重硬件、轻内容。有的基层馆花重金购置VR设备，却因缺乏适配内容长期闲置；大量文物数字化成果采完即存，展示仍以图片、文字、视频为主。中小博物馆藏品少、空间小、人才缺，数字化场景的轻量化构建是一条出路。

```
本作品是一台基于安路EG4S20的文物多成像实时阅览终端，把文物无损检测中的多成像比对方法，做成观众可以亲手操作的展项。

## 八、红线自查

| 红线 | 做法 | 结论 |
|---|---|---|
| 不得带处理器 | 全设计仅 EG4S20 | ✅ |
| 不得算法预处理 | 配准、融合、伪彩、缩放**全部逐帧实时计算** | ✅ |
| 不得预先渲染 | SD 卡里只有**各成像模式的原始图像**（等同"多台相机各拍一张"）与事件表，**没有任何融合后的预制画面** | ✅ |
| 素材真实性 | 演示数据如实标注来源与性质，不冒充真实检测结果 | ⚠️ 需在材料中说明 |

> **本方向在合规上特别干净**：融合系数、分界位置、缩放倍率都是观众实时改变的，**任何预渲染都覆盖不了这些组合**。
