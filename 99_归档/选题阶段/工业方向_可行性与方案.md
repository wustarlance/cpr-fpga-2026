# 工业方向：可行性与方案

> 结论：**可行，而且比博物馆方向更稳。** 撞车率低、产业需求真实、政策顺、技术底座完全复用。
> 核心判断：**工业现场要的不是更强的 CPU，而是"没有会坏的东西"。**

---

## 一、为什么工业方向站得住

### 1.1 市场够大

| 指标 | 数值 |
|---|---|
| 全球工业显示屏市场（2025） | 约 **67 亿美元**，预计 2032 年达 104.5 亿美元，CAGR 6.4% |
| 中国份额 | **超 35%**，全球最大单一市场；2025 年本土市场规模预计突破 **1390 亿元**（同比 +9%） |
| 全球工业显示终端安装量（2024） | 超 **230 万台** |
| 应用占比 | **工业控制（HMI）超 40%** 为最大场景 |
| 增长最快的品类 | 高亮度/阳光下可读/**宽温（-40℃~85℃）** 产品，需求增速 **28%** |

来源：[2026年TFT LCD工业显示屏市场现状与趋势分析](https://www.aoshite.net/lcdjishu5-2312.html)（数据引自 Grand View Research、Global Market Insights、QYResearch、Mordor Intelligence）

同一份报告的**行业核心痛点**原文：

> 「**极端环境适应性不足**（高温、低温、潮湿、粉尘）、高端核心部件依赖进口、定制化成本高、交付周期长、**软件生态不完善**，制约行业升级。」

### 1.2 痛点非常具体（这是最有力的部分）

来自工业一体机厂商的五年 TCO 拆解（2026-08-03）：

> 「在金属粉尘与切削液油雾并存的车间里，**风扇扇叶与散热鳍片是首批被堵塞的部件**。转速下降后主板温度持续走高，处理器进入降频保护后表现出的就是**软件卡顿与偶发重启**，每年因此产生的报修频次在多家离散制造企业的统计中**普遍高于两次**。售后工程师每次上门的人力成本加配件费用，**单次通常在数百到数千元不等**，叠加产线停机损失后差距会被进一步放大。」
> 「工业电脑一体机全年运行的环境温度跨度可达**零下十度到五十度**……商用级终端的工作温度通常**只覆盖 0 到 35 度**，部署在非控温车间时**故障率随季节波动明显**。」
> 「车间里**变频器、电焊机与大功率电机启停**时产生的传导干扰会沿电源线与信号线耦合到终端……参照 **GB/T 17626 系列标准**对静电放电、浪涌与电快速瞬变脉冲群做抗扰度考核，是避免**隐性重启**的工程基础。」
> 「无风扇方案采用全封闭铝合金机身与大面积被动散热鳍片，**取消了运动部件，从根源上消除积尘卡死这条失效路径**。」
> 「单点故障的现场处理时间从**整机返修的数天缩短至更换模块的十几分钟**。」

来源：[五年运维总投入拆解，工业电脑一体机风扇与无风扇路线的真实差距](https://www.szyocon.com/news/industry/4789.html)

### 1.3 最漂亮的一点：赛题的限制正好是这个行业要的东西

工业现场的失效清单，和我们架构里"没有的东西"，几乎是一一对应：

| 失效路径 | 工控机 + Windows | 本方案 |
|---|---|---|
| 风扇积尘卡死 → 降频 → 卡顿/重启 | **有（首要失效点）** | **无风扇** |
| 硬盘 / SSD 磨损 | 有 | **无（SD 卡只读）** |
| 操作系统崩溃、补丁、蓝屏 | 有 | **无操作系统** |
| 病毒 / 勒索软件 | 有 | **无从下手** |
| 意外断电导致文件系统损坏 | 有 | **只读，无损** |
| 启动时间长，恢复慢 | 数十秒 | **上电即出画面** |
| 授权 / 许可到期 | 有 | **无** |
| 功耗高，柜内温升大 | 有 | **低一个数量级** |

> **答辩时的核心句**：
> 「工业现场最怕的不是算力不够，是屏黑了。**我们的方案里没有会坏的部件。**」

## 二、五个具体子方向

| # | 子方向 | 痛点 | FPGA 真活 | 撞车率 |
|---|---|---|---|---|
| **A** | **设备状态显示终端**（流程图+曲线+仪表+报警） | 工控机在现场易死机、维护贵 | 流程图多图层实时渲染 + 趋势曲线 + 仪表指针 | **低** |
| B | 工位电子作业指导书（e-SOP） | 纸质 SOP 易错版、换型慢；PC 方案贵 | 多图步骤切换 + 关键件**实时放大** + 节拍计时 | 中低 |
| C | 新能源场站现场显示终端（光伏/储能/充电桩） | 无人值守、环境恶劣、宽温要求高 | 一次系统图 + 参数叠加 + 曲线 | 中低 |
| D | 设备点检 / 巡检终端 | 现场无网络、纸质记录易漏 | 检查表 + 部位图**平移放大** + 按键确认 | 中 |
| E | 产线安灯 / 状态看板 | 状态刷新与告警实时性 | 实时图形刷新 + 多区域状态色 | 中 |

**推荐 A**：技术含量最高（流程图 + 曲线 + 仪表三套渲染引擎），痛点最硬（直接对应"屏黑了"），演示最直观（曲线在动、指针在转、报警自动定位）。

## 三、推荐方案：工业设备状态显示终端

### 3.1 技术点

| 功能 | 为什么是实时计算 | 赛题对应 |
|---|---|---|
| **工艺流程图多图层渲染** | 底图 + 管路 + 设备图标 + 测点标注分层合成 | 透明叠加 |
| **画面平移与局部放大** | 流程图通常远大于屏幕，需实时平移与缩放查看局部 | **图片平移/局部放大** |
| **报警自动定位** | 报警触发时画面自动平移到对应测点并高亮 | 图形叠加 |
| **趋势曲线** | 滑动窗口 + 环形缓存逐列推进，多通道叠加 | 图形实时生成 |
| **仪表指针与刻度** | 按参数实时计算角度并平滑插值，不跳变 | 图形实时生成 |
| **时间轴回放** | 按键拖动时间轴，回放某段时间的设备状态与报警 | 按键交互 |
| **点阵字库实时缩放** | 不同观看距离的字号 | 字符显示 |
| **换型只换 SD 卡** | 内容与硬件解耦 | 多幅播放 |

**演示动作**：现场制造一次报警，画面**自动平移并放大**到出问题的测点，同时曲线标记时刻——一个动作同时展示"实时渲染 + 平移缩放 + 报警联动"。

### 3.2 内容解耦的产业价值

工业现场换型（产品切换）频繁，HMI 画面要跟着改。传统做法是重新组态、重新烧写、请工程师到场。
本方案：**换一张 SD 卡**。对多品种小批量的离散制造，这是实打实的降本。

## 四、合规性与能力边界（必须说清楚的两件事）

### 4.1 红线自查

| 红线 | 做法 | 结论 |
|---|---|---|
| 不得带处理器 | 全设计仅 EG4S20 | ✅ |
| 不得算法预处理 | 流程图、曲线、仪表**全部逐帧实时计算** | ✅ |
| 不得预先渲染 | SD 卡里只有**流程图底图与测点参数表**，没有预制画面 | ✅ |

### 4.2 ⚠️ 能力边界：不要过度声称

我们可以主张**架构上**减少了失效路径（无风扇、无 OS、只读存储）——这是设计事实。

**但不能声称"通过了宽温与 EMC 测试"**。GB/T 17626 系列（静电放电、浪涌、电快速瞬变脉冲群）和 -40℃~85℃ 宽温验证**需要专用测试设备**，学生团队做不了。

**建议口径**：
> 「本作品在**架构层面**消除了风扇、硬盘、操作系统三类主要失效路径，**宽温与 EMC 的实测验证属于后续工程化阶段的工作**。」

主动划清这条线，比被评委问出来要好得多。
