# 两个方向：菜单显示终端 / 户外健身器材使用指导终端

> 两条线都有**官方依据**支撑，且都天然覆盖赛题基础 4 条 + 扩展 5 条。

---

## 方向 A：菜单显示终端（建议做成"食谱公示"）

### 一、先说一个判断

单纯"播放菜单图片"是**电子相册**，技术含量低、也容易被问"为什么不用纸质"。**建议把镜头对准"必须公示的信息"**——这样菜单屏就有了法规层面的必要性。

### 二、官方依据（都是新规）

**洛阳市人大常委会《关于基础教育阶段校园餐有关事项公示的决定》**（2026年3月27日通过，6月1日公布）：

> 「**每周公示食谱**。配餐制学校每周公布**带量带价食谱**，选餐制学校每周公布带量食谱，均须在食堂**显著位置张贴**下周食谱，公示时间不少于7日」
> 「食谱应标明各菜品**主料、辅料名称、生重克数及执行价格**」
> 「每周公示**限制类餐品**供应情况。每周在带量食谱及相应售卖档口**明确标注**速成鸡鸭肉类餐品、油炸食品的具体菜品及供应时间」

**致敏物质**：GB 7718-2025《预包装食品标签通则》要求对**八大类致敏物质**（麸质谷物、甲壳类、鱼类、蛋类、花生、大豆、乳及乳制品、坚果）作出标示。

**现状问题**：这些信息目前多靠**纸质张贴**——字小、易被油污覆盖、被撕掉，**更新一次就要重印一次**。

### 三、为什么这个场景特别适合 SD 卡

| 信息 | 更新频率 | 是否适合 SD 卡 |
|---|---|---|
| 带量食谱 | **每周一次** | ✅ **完美匹配** |
| 主辅料生重克数、价格 | 每周随食谱变 | ✅ |
| 致敏物质标注 | 基本固定 | ✅ |
| 限制类餐品供应时间 | 每周 | ✅ |

> **一周更新一次的内容，用 SD 卡是最合理的选择**——比"秒级动态的叫号数据"合理得多。
> 而且 SD 卡可以一次预置**好几周的食谱**，按周切换即可。

### 四、产品形态

| 屏幕分区 | 内容 | 对应要求 |
|---|---|---|
| 主区 | 菜品图 + 名称 + **主料/辅料生重克数 + 执行价格** | 扩展①、③ |
| **标注层** | **八大类致敏物质**标注，可开关 | **扩展①** |
| 底部 | **滚动字幕**：限制类餐品供应时间、营养提示 | **扩展①（平滑滚动）** |
| 轮播 | 不同周的食谱、不同餐次按**转场**切换 | 扩展② |
| 角标 | 亮度 / 对比度**档位** OSD | **扩展④** |
| 音频 | 背景音乐 + **频谱** | 基础③、扩展⑤ |

**FPGA 优势落点**：**多图层并行合成**——菜品层、价格层、致敏标注层、滚动字幕层四层同时在线，逐像素并行取层合成，图层增加不拖累刷新。

## 方向 B：户外健身器材使用指导终端

### 一、官方依据（这条比菜单方向更硬）

**市场监管部门《室外健身器材产品使用提示》**（2025-06-20）原文：

> 「公共健身器材常见的安全隐患有以下几种：一是设施老化，二是配件缺损，三是「**缺少使用方法和注意事项**」。」
> 「**标志不清、警示不足**，器械在使用过程中会出现碰撞和跌落等危险，易造成使用者和旁人的人身伤害。」

同文要求使用者「应**仔细阅读其上贴着的使用说明和适用人群**」——**但器械上贴的就是一张金属标牌，经风吹日晒后字迹模糊。**

**供给规模**（新华社，2026年全国群众体育工作会议）：

- 截至 2025 年底，全国共有体育场地 **500.37 万个**，人均体育场地面积 **3.11 平方米**
- 「**15 分钟健身圈**」基本实现
- 「国球两进」累计配建**其他各类健身设施 13.5 万件（处）**，覆盖社区超 2 万个、公园超 5000 个
- 2025 年经常参加体育锻炼人数比例 **38.52%**，体质合格率 **84.9%**

### 二、痛点提炼

**器械不会用、用错会受伤，而指导信息恰恰看不清。** 官方自己把它列为三大安全隐患之一。

### 三、产品形态

装在**器械组旁**的一块屏，按键切换查看不同器械。

| 屏幕分区 | 内容 | 对应要求 |
|---|---|---|
| 主区 | **标准动作图示**轮播 | 扩展①、② |
| **标注层** | **手部/脚部着力点、动作幅度**标注，可开关 | **扩展①** |
| 底部 | **滚动字幕**安全提示 | **扩展①（平滑滚动）** |
| 放大 | 按键放大看动作幅度、平移画面 | 扩展③ |
| 角标 | 亮度 / 对比度**档位** OSD | **扩展④** |
| 音频 | 节拍音乐 + **频谱** | 基础③、扩展⑤ |

**安全提示直接来自官方文件**（可原文上屏）：
- 最大承重 **120 kg**
- **12 岁以下儿童**应在家人的看护下使用
- 运动范围边缘向外 **至少 1500 mm** 内请勿靠近
- **严禁在器材和辅助设施上攀爬**
- 有心脏病、高血压、哮喘等患者应在医生指导下使用

**FPGA 优势落点**：**低功耗 + 高可靠性**——无操作系统，常年不关机也不死机；功耗远低于工控机，**可配太阳能与蓄电池**，直接解决户外供电；上电即出画面。

器械使用说明是**几乎不更新的静态内容**——一次写入，用几年。这是 SD 卡最合适的用法。

## 两个方向横向对比

| | A 食谱公示 | B 户外健身器材指导 |
|---|---|---|
| 官方依据强度 | **强**（地方人大决定 + 国标） | **最强**（监管部门把问题列为安全隐患） |
| 痛点紧迫性 | 合规公示，不做会被查 | **人身安全**，不做会伤人 |
| 供给规模 | 全国学校与单位食堂 | 健身设施 **13.5 万件（处）**、体育场地 500 万个 |
| SD 卡合理性 | ✅ 每周更新一次，完美匹配 | ✅ **静态内容，一次写入用几年** |
| FPGA 优势落点 | 多图层并行合成 | **低功耗 + 太阳能 + 常年不死机** |
| 场景独特性 | 中（菜单屏有人做，公示屏少见） | **高**（几乎没人做） |

**我的建议：方向 B（户外健身器材使用指导终端）。**

理由：
1. **依据最硬**——官方自己说"缺少使用方法和注意事项"是安全隐患，我们就是在解决这个
2. **SD 卡最合理**——内容几乎不更新，一次写入用几年，完全绕开了"为什么不用网络"的质疑
3. **FPGA 优势最自然**——户外无电、无人值守，"低功耗 + 太阳能 + 常年不死机"是真需求不是硬凑
4. **撞车概率最低**——几乎不会有人想到做这个
