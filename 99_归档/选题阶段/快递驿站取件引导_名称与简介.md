> 「货架上有三四个蓝灯在闪，根本分不清哪个是我的」
> 「灯光持续时间有限，还没找到包裹，灯就自动熄灭，又得重新操作一遍」
> 「驿站通常只有一名工作人员……高峰时段，队伍能排到驿站门外」

**一句话价值**：**不用下载 App，抬头看屏就知道东西在哪个货架第几层。**

## 三、作品简介

### ★ A_逐条对应版 —— 490 字（含换行）/ 488 字（去空白）

> 结构最贴评分表。**推荐用于报名表与作品提交。**

```
2026年1月，天津日报报道快递驿站取件乱象：取件要先下载电商平台App、绑定手机、查码、扫码，“不熟悉流程的费劲，眼神不好的费劲、年岁大的也费劲”；包裹上的感应灯同时亮起，“三四个蓝灯在闪，根本分不清哪个是我的”，灯灭就得重来，有人找一件快递花了十多分钟，高峰时队伍排到门外。天津市邮政管理局回应，不得强制或变相强制用户下载使用特定软件。
本作品是一台快递驿站取件引导终端，以国产安路EG4S20为核心，全部算法与控制逻辑在FPGA内自主编程实现，无任何处理器。终端扫描SD卡图像、解析BMP文件并写入SDRAM帧缓存，经HDMI同时输出视频与音频；由FPGA自主实现的串口接收器接收驿站系统推送的取件信息，两路数据在像素流水线内融合。
扩展功能逐条实现：①货架图、包裹位置标注与取件码分层叠加，待取列表与提示文字由片内点阵字库渲染并平滑滚动；②列表更新与切换带淡入淡出与滑动转场；③按键放大货架图并平移查看层位；④按键调节亮度对比度并显示档位；⑤语音播报取件码时以多段滤波器组生成同步频谱。取件人无需下载App、无需操作手机，抬头即可看到包裹所在货架；更换布局只需替换SD卡。
```

### B_技术机制版 —— 411 字（含换行）/ 409 字（去空白）

> 面向技术评委，把"两路数据如何在 FPGA 内汇合"讲透。

```
本作品是一台基于安路EG4S20的快递驿站取件引导终端，把“包裹在哪个货架第几层”直接显示在驿站墙上，取件人无需下载App、无需操作手机。
终端扫描SD卡图像资源、解析BMP文件并写入SDRAM帧缓存；同时由FPGA自主实现的串口接收器接收驿站系统推送的取件码与货位信息，写入独立的显示缓存。两路数据在像素流水线内汇合：每个像素的取址、多层读取、透明色比较与合成在一拍内完成，取件信息到达后下一帧即上屏，时序确定、无软件调度抖动。货架底图、包裹位置标注、取件码与待取列表分层叠加，提示文字由片内点阵字库实时渲染并平滑滚动；语音播报取件码时以多段滤波器组生成同步频谱。
扩展功能逐条实现：①图层叠加与平滑滚动字幕；②列表更新与页面切换的淡入淡出与滑动转场；③货架图的放大与平移；④亮度与对比度调节并显示档位；⑤多段滤波器组生成音频频谱。全部算法与控制逻辑在FPGA内自主编程实现，无任何处理器；上电即出画面，营业全程不死机。
```

### C_场景体验版 —— 338 字（含换行）/ 336 字（去空白）

> 面向答辩开场、宣传文案。开篇三段就是取件人的真实处境。

```
在快递驿站取个件，先要下载App、绑定手机、查取件码、再扫码；包裹上的灯同时亮起，三四个蓝灯闪成一片，分不清哪个是自己的；灯灭了还得重来一遍。天津一位取件人为此花了十多分钟，高峰时队伍排到驿站门外。
本作品换了一条路：墙上那块屏直接把“你的包裹在3号货架第2层”显示出来。它以国产安路EG4S20为核心，从SD卡读取货架图与宣传素材，经本地串口接收驿站系统推送的取件信息，两路数据在FPGA的像素流水线内实时合成——货架图、包裹位置标注、取件码与待取列表分层叠加，提示文字平滑滚动，语音播报取件码时频谱同步跳动。
不下载App、不扫码、不找灯，抬头看一眼就行。全部算法与控制逻辑在FPGA内自主编程实现，无任何处理器；上电即出画面，营业全程不死机；更换货架布局只需替换SD卡。
```
