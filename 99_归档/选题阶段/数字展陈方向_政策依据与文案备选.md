## 一、结论先说

1. **政策依据是充分的，而且方向很正**：中央层面有《关于推进实施国家文化数字化战略的意见》，部委层面有《"十四五"文物保护和科技创新规划》和最新的《国家文物事业发展"十五五"规划》，法律层面还有《无障碍环境建设法》可叠加。四条线能同时命中，这在赛道里不多见。
2. **最有力的一句政策原文**是文化数字化战略里的「大力发展线上线下一体化、**在线在场相结合**的数字化文化新体验」。我们的方案是"在场"的离线终端，正好落在这句话上。
3. **最有力的一个数据**不是"博物馆有7188家"，而是**"当年仅 17.68% 的科技馆更新过常设展厅"** —— 它把需求从"文化很重要"变成了"基层场馆换不起展"，这才是我们方案要解决的问题。
4. 名称推荐 **「声画长卷交互式数字展陈终端」**（13 字）；简介推荐 **A_推荐版**（486 字，含换行），见第五、六节。

### 2.1 中共中央办公厅、国务院办公厅《关于推进实施国家文化数字化战略的意见》（2022-05-22）

**原文（可直引）**
- 「到2035年，建成物理分布、逻辑关联、快速链接、高效搜索、全面共享、重点集成的国家文化大数据体系，**中华文化全景呈现，中华文化数字化成果全民共享**。」
- 八项重点任务之五：「**发展数字化文化消费新场景，大力发展线上线下一体化、在线在场相结合的数字化文化新体验**。」
- 八项重点任务之六：「统筹推进国家文化大数据体系、全国智慧图书馆体系和公共文化云建设，增强公共文化数字内容的供给能力，**提升公共文化服务数字化水平**。」

**映射到我们的设计**
上述第五条里的「在线在场相结合」是本方案最贴的政策抓手。我们的终端不依赖网络、不依赖云，是部署在展厅里的"在场"节点，上电即播、离线运行——这正是"在场"那一半，且成本低到可以铺进基层场馆，与"全民共享"呼应。

## 四、痛点提炼与合规性核对

### 4.1 三段式痛点（写简介、答辩都用这一套）

1. **供给端：内容多到管不过来。** 7188 家博物馆 + 622 座科技馆 + 10 万余项非遗项目 + 1.08 亿件可移动文物，需要被阐释的内容是海量的。
2. **场馆端：换不起展。** 科技馆里 62% 是县级馆、71% 是小馆，而当年只有 **17.68%** 的馆更新过常设展厅。现有数字展陈方案普遍依赖 PC / 工控机 / 专业播放器，采购贵、功耗高、故障点多、需专人维护，内容更新还得重新渲染打包——**小馆不是不想换，是换不起、也不会换**。
3. **观众端：看不懂、也看不清。** 专业展陈文本没有分层表达；老人看不清小字、听障观众听不到旁白、境外游客看不懂中文，同一件展品对不同人群几乎是不同的东西。

### 4.2 红线对照（安路赛道选题一）

安路赛题明确要求：**不得带有额外处理器（无论用于辅助控制还是算法预处理）**。本方案逐条自查：

| 红线 | 我们的做法 | 是否合规 |
|---|---|---|
| 不得带处理器 | 全设计仅 EG4S20 一颗 FPGA，无 MCU/ARM/软核 CPU | ✅ |
| 不得算法预处理 | 文字由片内点阵字库**实时**缩放渲染；缩放/平移/叠加**实时**在 FPGA 内完成 | ✅ |
| 不得把文字预先渲染成 BMP 再播放 | 素材只有点阵字库文件 + 长卷底图；**字幕从不预渲染** | ✅ |
| 素材本身可以预先生成？ | 长卷底图是"原始素材"，不是"为绕过 FPGA 而做的预计算"；但**答辩时必须主动说明这条边界** | ⚠️ 需准备口径 |

> **口径建议**：主动区分「美术素材」与「算法预处理」。底图是画作本身，本来就存在于展馆；而我们没有把"缩放后的图""渲染好的字幕条"这类**本该由 FPGA 算出来的中间结果**预先做好。这一点最好在答辩 PPT 里用一页画清楚，否则容易被质疑。

### 4.3 功能点覆盖度（诚实版）

| 题目要求的功能点 | 本方案 | 说明 |
|---|---|---|
| 多幅图像播放（≥4 幅） | ✅ | 长卷分段 + 事件表驱动 |
| 透明叠加 / 透明色处理 | ✅ | 多图层 alpha 混合 |
| 按键交互（≥2 按键） | ✅ | 播放控制 |
| 图片平移 / 局部放大 | ✅ | 长卷平移 + 局部细节放大 |
| 音频播放（旁白） | ✅ | I2S + SD 卡 PCM/WAV |
| **音频可视化** | ⚠️ | **未实现前不要对外声称 5/5** |

> **建议**：宣传口径统一按 **4/5**，音频可视化做出来了再改成 5/5。实现路径建议用 **8 段滤波器组 + 能量检测**（比 FFT 省资源，EG4S20 无 DSP 硬核），把能量映射成屏幕边缘的律动条即可。
