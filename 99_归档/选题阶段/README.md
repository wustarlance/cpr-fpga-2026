> 归档日期：2026-09-24
> **这些文件没有被删除，只是从 `03_技术方案/` 挪到了这里。**

## 为什么归档

立项阶段我们探索过 **十多个候选方向**（博物馆陈列、古籍阅览、外卖取餐、工业质检、
户外健身、快递驿站、数字展陈、应急避险、视障无障碍、声画长卷……），
最终**定稿为「心肺复苏实时反馈训练终端」**。

这些是**没有采用的方向的草稿**。留在 `03_技术方案/` 里会有两个问题：

1. **答辩时评委会困惑** —— 翻到这些文件会问"你们到底想做哪个？"
2. **干扰检索** —— 搜关键词时混进大量无关内容

## 为什么不是删除

- 它们记录了**完整的比选过程**，是"我们认真选过题"的证据
- 万一将来需要换个方向、或答辩需要讲比选逻辑，还能翻出来
- 项目今天已经被误删过一次，能不删就不删
