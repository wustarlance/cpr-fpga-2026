# 方向 1、3、4：名称与作品简介定稿

> 三个方向均**跳出赛题列举的五个场景**，且都能**自然覆盖扩展要求①~⑤**。
> 简介结构统一为三段：**场景与痛点 → FPGA 优势 + 基础要求 → 扩展要求逐条实现**。

---

## 方向一：舞台提词与画面终端

### 一句话
> **给舞台配一块屏：提词滚动不抖，背景画面跟着节目换，亮度跟着灯光调。**

| 项 | 内容 |
|---|---|
| **场所** | 校园晚会、婚礼现场、企业年会、小型剧场、会议室 |
| **用户** | 主持人、演讲者、演出团队、会务人员 |
| **现在怎么做** | 笔记本接投影：接线多、开机慢、现场断电就黑屏；提词器还要另配一台设备 |
| **痛点** | 忘词；背景画面要跟着节目换；舞台灯光反复明暗剧变；没人有空盯电脑 |

### FPGA 优势（一句话能讲清）
> **提词的滚动不能抖。通用方案会抖，FPGA 不会。**

滚动位置由像素时钟直接驱动，**每一帧位移严格相等**，不存在软件调度抖动；视频与音频由同一套时序基准驱动，音画严格同步。

### 作品名称候选（均 ≤15 字）

| 字数 | 名称 | 点评 |
|---|---|---|
| **9** | **舞台提词与画面终端** | ★ **推荐**。两个核心功能都在名字里，场景清晰 |
| 8 | 演出提词显示终端 | 更简洁，但丢了"画面" |
| 9 | 提词与画面合成终端 | 点出"合成"这个机制 |
| 8 | 舞台提词显示终端 | 稳妥 |
| 9 | 多图层提词显示终端 | 技术视角 |
| 9 | 提词与背景画面终端 | 强调"背景画面" |
| 9 | 演出提词与画面终端 | 推荐的近义版 |
| 6 | 舞台提词终端 | 最短，但功能感弱 |

> **海报主标题建议**：`提词不抖，才是专业`

### 作品简介 —— 404 字（含换行）/ 402 字（去空白）

```
校园晚会、婚礼与企业年会的舞台上，主持人忘词、背景画面要跟着节目换、灯光在明暗之间反复切换，而现场常见的笔记本加投影方案接线多、开机慢，一旦断电就黑屏。
本作品是一台舞台提词与画面终端：以国产安路EG4S20为核心，全部算法与控制逻辑在FPGA内自主编程实现，不含任何处理器。终端扫描SD卡素材、解析BMP文件并存入SDRAM帧缓存，经HDMI同时输出视频与音频。提词滚动位置由像素时钟直接驱动，每帧位移严格相等，不存在软件调度抖动，演讲者不会跟丢；视频与音频由同一套时序基准驱动，音画严格同步；上电即出画面，意外断电来电立刻恢复。
扩展功能逐条实现：①提词滚动字幕支持速度可调与暂停，画面由多层实时合成；②节目切换带淡入淡出与滑动过渡；③按观看距离自适应缩放字号与画面；④按键调节亮度与对比度并在屏上显示当前档位，适应舞台灯光剧变；⑤背景音乐以多段滤波器组提取能量，生成频谱随节奏起伏。换场只需替换SD卡。
```

## 方向三：社区健身教学显示终端

### 一句话
> **给社区健身队配一块屏：动作要领滚着放，关键部位标出来，音乐节拍看得见。**

| 项 | 内容 |
|---|---|
| **场所** | 社区广场、公园、健身步道、乡镇文体站 |
| **用户** | 社区居民、广场舞领队、文体站管理员 |
| **现在怎么做** | 领队自带音响和纸质动作图；动作要领靠口传 |
| **痛点** | 户外光线从清晨到夜晚跨度极大；无人值守要常年开机；户外供电不方便 |

### FPGA 优势
> **常年不关机也不死机，功耗低到能用太阳能。**

无操作系统，没有死机、病毒、文件系统损坏三类失效路径；功耗远低于工控机，可配太阳能板与蓄电池解决户外供电；每个像素的取址、多层读取、透明色比较与合成均在像素时钟内一拍完成，时序确定、画面不抖。

### 作品名称候选（均 ≤15 字）

| 字数 | 名称 | 点评 |
|---|---|---|
| **10** | **社区健身教学显示终端** | ★ **推荐**。场景准确，"社区"点出公共服务属性 |
| 8 | 户外健身指导终端 | 突出"户外"这个真实约束 |
| 8 | 广场健身教学终端 | 通俗易懂，但"广场舞"略显窄 |
| 8 | 社区健身指导终端 | 简洁 |
| 8 | 户外健身教学终端 | 推荐的近义版 |
| 8 | 户外健身显示终端 | 最短的完整版 |
| 9 | 多图层健身教学终端 | 技术视角 |
| 8 | 社区文体教学终端 | 覆盖面更宽 |

> **海报主标题建议**：`太阳晒着也能看清，一年不关机`

### 作品简介 —— 426 字（含换行）/ 424 字（去空白）

```
社区广场和乡镇文体站的健身队，领队要自带音响和纸质动作图，动作要领靠口传；户外光线从清晨到夜晚跨度极大，场地无人值守，供电也不方便。
本作品是一台社区健身教学显示终端：以国产安路EG4S20为核心，全部算法与控制逻辑在FPGA内自主编程实现，不含任何处理器。终端扫描SD卡素材、解析BMP文件并存入SDRAM帧缓存，经HDMI同时输出视频与音频；每个像素的取址、多层读取、透明色比较与合成均在像素时钟内一拍完成，时序确定、画面不抖；无操作系统，常年不关机也不会死机，功耗远低于工控机，可配太阳能板与蓄电池，解决户外供电；视频与音频由同一套时序基准驱动，节拍与音乐严格同步；上电即出画面。
扩展功能逐条实现：①动作要领以滚动字幕呈现，关键部位用标注层实时叠加；②分解动作轮播并带淡入淡出转场；③可放大查看某一动作细节；④按键调节亮度与对比度并在屏上显示当前档位，适应户外光变；⑤以多段滤波器组提取音乐能量，生成节拍频谱帮助队员跟拍。换曲目只需替换SD卡。
```

## 方向四：门店叫号与菜单显示终端

### 一句话
> **给小店配一块屏：叫号滚着显示，菜单轮着播，背景音乐跟着放。**

| 项 | 内容 |
|---|---|
| **场所** | 快餐店、茶饮店、单位食堂、社区食堂 |
| **用户** | 店员、顾客 |
| **现在怎么做** | 叫号靠喊；菜单贴在墙上，换季要重印；音响单独一台 |
| **痛点** | 嘈杂环境听不见叫号；菜单换季就要重做；柜台上设备越堆越多 |

### FPGA 优势
> **四层画面同时在，图层多了也不掉帧。**

叫号层、菜单层、字幕层与频谱层由硬件并行取层合成——640×480 下每秒 1843 万像素的取址、四层读取、透明色比较与合成均在像素时钟内一拍完成；视频与音频由同一套时序基准驱动，音画严格同步。

### 作品名称候选（均 ≤15 字）

| 字数 | 名称 | 点评 |
|---|---|---|
| **11** | **门店叫号与菜单显示终端** | ★ **推荐**。两个功能都在，场景明确 |
| 9 | 叫号与菜单合成终端 | 点出"合成"机制，更技术 |
| 9 | 门店叫号与菜单终端 | 推荐的短版 |
| 9 | 叫号与菜单显示终端 | 简洁准确 |
| 8 | 门店信息显示终端 | 覆盖面宽，但没点出叫号 |
| 8 | 叫号菜单显示终端 | 最短的完整版 |
| 8 | 门店叫号显示终端 | 只讲叫号 |
| 9 | 多图层门店显示终端 | 技术视角 |

> **海报主标题建议**：`听不见，也看得见`

### 作品简介 —— 404 字（含换行）/ 402 字（去空白）

```
快餐店、茶饮店和单位食堂里，叫号靠喊，嘈杂环境常常听不见；菜单换季就得重印；柜台上播放器、菜单牌、音响越堆越多。
本作品是一台门店叫号与菜单显示终端：以国产安路EG4S20为核心，全部算法与控制逻辑在FPGA内自主编程实现，不含任何处理器。终端扫描SD卡素材、解析BMP文件并存入SDRAM帧缓存，经HDMI同时输出视频与音频；640×480下每秒1843万像素的取址、四层读取、透明色比较与合成均在像素时钟内一拍完成，图层增加不拖累刷新；视频与音频由同一套时序基准驱动，音画严格同步；营业时间全程运行不死机，上电即出画面。
扩展功能逐条实现：①叫号号码与提示语滚动显示，菜单与文字多层实时叠加；②菜单轮播带淡入淡出与滑动转场；③按键放大菜品图；④按键调节亮度与对比度并在屏上显示当前档位，适应白天与夜间；⑤背景音乐以多段滤波器组提取能量，生成频谱条。换季只需替换SD卡中的菜单图与文案，无需重新综合与烧写。
```
