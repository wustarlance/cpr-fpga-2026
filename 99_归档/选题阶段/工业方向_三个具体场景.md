# 工业方向：三个具体应用场景

> 依据 2026 年最新的两份政策文件与近期新闻，给出三个**有明确政策抓手、有真实用户、有具体动作**的工业场景。
> 三者共用同一套技术底座，区别在于**渲染什么图形**。

---

## 一、共同的政策底座（都是最新原文）

### 1.1 工信部「十五五」新型工业化路线图（2026-08-26 国新办发布会）

原话摘录：

> 「创新"**一业一图谱、一景一档案**"场景培育新模式，推出一批「**轻量化、低成本、易部署**」的行业解决方案」
> 「组织实施**传统产业焕新行动**，以智能化、绿色化、融合化为方向，深化制造业新型技术改造城市试点……**推进石化化工老旧装置更新改造**」
> 「培育建设 **500 家零碳工厂**，落地动力电池数字身份证管理制度」
> 「开发更多「**小快轻准**」数字化转型产品」
> 「全链条推动……**工业母机**、高端仪器仪表、基础软件和工业软件……关键核心技术攻关取得决定性突破」

来源：[工信部详解"十五五"新型工业化路线图（证券时报，2026-08-27）](https://www.cnfin.com/hg-lb/detail/20260827/4460985_1.html)

### 1.2 发改委、财政部《关于2026年实施大规模设备更新和消费品以旧换新政策的通知》（发改环资〔2025〕1745号）

原话摘录：

> 「优化申报条件和审核流程，**进一步降低申报设备更新项目的投资额门槛，加大对中小企业设备更新的支持力度**，扩大政策惠及面」
> 支持领域明确包含：工业、电子信息、能源电力……**安全生产**……节能降碳环保

来源：[中国政府网](https://www.gov.cn/zhengce/zhengceku/202512/content_7053236.htm)

### 1.3 这两句话指向同一个结论

> **政策正在把钱往"中小企业"和"轻量化方案"上引。**

大企业上西门子、罗克韦尔；**中小企业买不起工控机，也养不起**。而"降低投资额门槛""小快轻准""轻量化、低成本、易部署"——这些词描述的正是无操作系统、无风扇、上电即亮、换卡即用的终端。

**三个场景的客户都是中小企业。**

## 二、场景 ①：老旧设备加装式状态显示终端

### 一句话
> **给没有屏、或原厂屏早已停产的老机床、注塑机、空压机，加一块"看得懂状态"的屏。**

| 项 | 内容 |
|---|---|
| **政策抓手** | 发改委设备更新政策「**降低投资额门槛，加大对中小企业设备更新的支持力度**」；工信部「**小快轻准**」数字化转型产品 |
| **用户** | 中小制造企业的设备科、班组长、操作工 |
| **场所** | 车间机台旁，嵌入控制柜面板或悬挂在机台侧壁 |
| **现在怎么做** | 没屏就靠经验听声音、看电流表；有屏的原厂面板停产，坏了没法修；升级方案是换整机或装工控机 |
| **问题** | 换整机太贵；工控机在粉尘油雾环境下风扇积尘、降频、卡顿重启，每年报修超过两次 |

**我们的终端做什么**

- SD 卡读取设备参数与画面表，HDMI 直驱显示
- FPGA 实时绘制**仪表指针、参数数值、趋势曲线**
- 按键翻页切换参数页；按键平移放大看曲线细节
- 无处理器、无操作系统、无风扇、无硬盘 → **可采用全封闭无风扇结构**
- 上电即出画面；换一台设备只需换 SD 卡

**演示动作**：把"转速"参数从 1200 连续调到 3000，仪表指针**平滑转过**、曲线同步上扬——实时算的，不是放动画。

## 三、场景 ②：石化化工装置现场参数显示终端

### 一句话
> **在化工装置区，用一块不怕环境、不怕断电的屏，显示带参数叠加的工艺流程图。**

| 项 | 内容 |
|---|---|
| **政策抓手** | 工信部原话「**推进石化化工老旧装置更新改造**」；发改委设备更新支持领域含「**安全生产**」 |
| **用户** | 装置操作工、巡检工、开停车作业人员 |
| **场所** | 装置区非防爆的控制室、巡检点、机柜间 |
| **现在怎么做** | DCS 画面在中央控制室，现场看不到；现场靠纸质工艺卡片与巡检表 |
| **问题** | 工控机在高温、腐蚀性气体与强电磁干扰环境下故障率高；专用防爆终端价格昂贵，中小企业承担不起 |

**我们的终端做什么**

- 大尺寸**工艺流程图**（远大于屏幕），支持按键**平移与局部放大**查看任意工段
- 图上各测点**实时叠加参数数值与状态色**
- **报警时画面自动平移到对应测点并高亮**
- 无操作系统 → 上电即出画面，意外断电后重新来电立刻恢复

**演示动作**：制造一次报警，画面**自动平移并放大**到出问题的测点——一个动作同时展示实时渲染、平移缩放、报警联动。

> ⚠️ **能力边界**：本终端**不具备防爆认证**，只适用于非防爆区域。这一点必须主动说明。

## 四、场景 ③：零碳工厂车间能耗与碳排放在线看板

### 一句话
> **把工厂的能耗与碳排放，从办公电脑搬到车间现场。**

| 项 | 内容 |
|---|---|
| **政策抓手** | 工信部原话「培育建设 **500 家零碳工厂**，落地动力电池数字身份证管理制度」；绿色低碳转型是"十五五"工业高质量发展重要主线 |
| **辅助新闻** | 2026 年 9 月，**我国光伏发电装机历史性超过煤电**（国家能源局）——能源结构转型加速，企业能耗管理压力上升 |
| **用户** | 工厂能源管理员、车间主任、参观来访者 |
| **场所** | 车间入口、能源管理站、参观通道 |
| **现在怎么做** | 能耗管理系统部署在服务器与办公电脑上，车间现场看不到；老板要数据得打电话 |
| **问题** | 车间有电磁干扰与粉尘，不适合摆普通电脑；屏幕常年开着，工控机功耗与故障都是负担 |

**我们的终端做什么**

- FPGA 实时绘制**分项能耗柱状图**（矩形填充实时生成）
- **占比环形图**、**总能耗趋势曲线**、**碳排放累计值**
- 按键切换车间、切换时间范围（班/日/月）
- 功耗远低于工控机，可常年不关机

**演示动作**：按键切换时间范围，柱状图与趋势曲线**当场重算重绘**，碳排放数值同步跳变。

## 五、三者对比

| | ① 老旧设备加装 | ② 化工装置现场 | ③ 零碳工厂看板 |
|---|---|---|---|
| 政策抓手强度 | **最强**（原话直指中小企业） | 强（有原话） | 强（有量化指标 500 家） |
| 客户数量 | **最多**（中小企业存量设备） | 少（高危行业） | 中（规模以上工厂） |
| 核心技术 | 仪表指针 + 曲线 | **流程图平移缩放 + 报警定位** | **图表渲染（柱状/环形）+ 曲线** |
| 撞车率 | 低 | **极低** | 低 |
| 演示直观度 | 好（指针转、曲线动） | 好（报警自动定位） | **最好**（图表跳变很直观） |
| 实现难度 | 中（指针要算 sin/cos） | 中高（流程图 + 定位） | **中低**（柱状图是矩形填充，最简单） |

### 推荐

- **想要政策最贴、市场最大** → **①**
- **想要撞车率最低、最专业** → **②**
- **想要实现最简、演示最直观、且踩中"双碳"** → **③**

**如果让我选一个：③。** 理由是——政策最新（500 家零碳工厂是"十五五"新增量化指标）、技术上最省（柱状图/环形图比指针和流程图都好写）、演示最直观（按键一切，图表整个跳变）、而且"双碳"是评委都熟悉的长线国策。

## 六、名称与简介

### 场景 ①

**名称推荐**：`设备状态加装显示终端`（10字）／`老旧设备加装式显示终端`（11字）／`加装式设备状态终端`（9字）

```
国家发展改革委、财政部《关于2026年实施大规模设备更新和消费品以旧换新政策的通知》明确提出，进一步降低申报设备更新项目的投资额门槛，加大对中小企业设备更新的支持力度；工业和信息化部在“十五五”新型工业化部署中也要求开发更多“小快轻准”数字化转型产品，推出轻量化、低成本、易部署的行业解决方案。
中小制造企业的大量在用设备——老机床、注塑机、空压机、水泵——要么没有显示面板，要么原厂面板早已停产，操作工只能靠经验判断运行状态。换整机太贵，装工控机又要面对粉尘、油雾、宽温与电磁干扰。

```

## 七、共同的红线自查

| 红线 | 做法 | 结论 |

| 不得带处理器 | 全设计仅 EG4S20 | ✅ |
