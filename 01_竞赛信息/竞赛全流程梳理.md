## 二、题目要求（依据：安路选题指南）

> ✅ **赛道已确认：安路选题一**
> 权威依据 = `FPGA赛题/安路信息科技.pdf` → 已转成工作区里的 **`选题一_安路HDMI多媒体播放系统.md`**
> 康芯那份 DOCX 是**另一家主办方**的版本，你不适用；可作参考，但**不作为依据**。

### ⚠️ 一条硬约束（安路特有，务必注意）

> 参赛作品中所展示的所有算法、控制逻辑及数据处理流程应**在 FPGA 中自主编程实现**。允许根据作品需要搭配外围电路或成品模块，但**不得带有额外处理器**（无论用于辅助控制还是算法预处理）。

**含义**：不能用单片机 / 树莓派 / PC 端做任何辅助或预处理，**全部逻辑必须在 FPGA 内**。

**但有个口子**：原文明确允许**多块同款 FPGA 板卡**构建主从结构、自定义链路互联。如果能申请到第二块板，这是正当的扩展路径。

### 好消息：安路版没有"不能照抄参考例程"那条红线

康芯版写了"整体实现架构、音频和图片处理方法不能和参考实例相同"，**安路版没有这句**。安路只要求"自主设计并实现""在 FPGA 中自主编程实现"。

**实际影响**：
- ✅ 可以**放心研读和借鉴**参考例程（`lab_ex4_tf` / `lab_ex5_i2s`）
- ✅ 不需要为了"不一样"而故意绕路，7.5 周的压力小了很多
- ⚠️ 但"自主编程实现"意味着**得自己写 HDL、自己跑通**，不能拿现成位流交差
- ⚠️ 评分含"创新性与实用性"，**适度差异化仍对扩展分有利**

### 基础要求（安路写成 4 个评分维度）

| # | 维度 | 对应功能（见 1.3 赛题要求） |
|---|---|---|
| 1 | 核心功能完整性 | 本地图像资源扫描、BMP 解析、SDRAM 帧缓存管理、HDMI 视频显示、HDMI 音频输出、交互控制、音视频联动展示 |
| 2 | 显示稳定性与鲁棒性 | 画面连续清晰，无黑屏卡死、无持续斑点、无长期花屏、无明显撕裂 |
| 3 | 基础音频输出 | 音频链路稳定，终端能正常枚举并出声 |
| 4 | 系统工程规范性 | 工程结构、文档、可维护性 |

**注意**：安路版**没有写死**"≥4 幅 640×480 图""≥2 个按键"这些数字（那是康芯版写的）。功能范围两者一致，**建议仍按 ≥4 幅图 / ≥2 按键 / 轮播周期可配 来做**——这是合理下限。

### 扩展要求（安路版 5 项）

| # | 扩展项 | 技术要点 |
|---|---|---|
| ① | 图层叠加与字幕效果 | 多图层混合、动态文字、平滑滚动 |
| ② | 图片切换与转场特效 | 淡入淡出、滑动等 |
| ③ | 图片缩放适配 | 读取不同分辨率并缩放，鼓励优化缩放质量 |
| ④ | 实时调节与信息叠加 | 板载开关/按键调亮度对比度，画面呈现参数变化 |
| ⑤ | 音频可视化表现 | 频谱或波形叠加于视频画面 |

**评分策略**（原文）：完成 1 项有分；2 项且效果良好可得扩展部分一半以上；3 项以上且完成度高可得高分；完成度高、创新突出可满分。

→ **不要贪多，先保 2 项做扎实。** 建议选 **②转场特效 + ④实时调节与 OSD**：

- ② 与基础功能耦合紧，做了顺带提升"显示稳定性"的观感
- ④ 的 OSD 叠加可复用 ① 的图层混合逻辑，性价比高
- ⑤ 需要 FFT 或滤波器组，EG4S20 无 DSP 硬核，7.5 周内投入产出比低

### 自备设备（三选一，现在就该准备）

1. 支持 HDMI 音视频输入的电视 / 带喇叭的显示器
2. 支持 HDMI 音视频输入的显示器 + 外接音箱
3. HDMI 转 VGA、音频输出转接器 + VGA 显示器 + 音箱

→ **决赛要现场演示，别到最后一刻才发现显示器没喇叭。**

| 项 | 官方要求 |

| 音频 | 官方选题一 1.5 **漏写**了"带扬声器"（选题二写了），但**基础要求(4) 要求 HDMI 音频输出** → **仍必须带喇叭或音频输出** |

## 三、系统长什么样

```
  ┌─────────┐
  │  TF 卡  │
  └────┬────┘
       │ SPI
  ┌────▼─────────────────┐
  │  媒体读取层           │  扇区读 + FAT32 目录 + BMP 解析
  └────┬─────────────────┘
       │ 像素流
  ┌────▼─────────────────┐
  │  SDRAM 帧缓存         │  2M×32bit（8MB），双缓冲
  └────┬─────────────────┘
       │
  ┌────▼─────────────────┐   ← 你们的核心创新点在这里
  │  像素处理流水线       │  LUT 校正 / Alpha 混合 / 缩放
  └────┬─────────────────┘
       │
  ┌────▼─────────────────┐
  │  HDMI 输出层          │  视频时序 + 音频打包
  │  （发射核是加密 IP）  │
  └────┬─────────────────┘
       │
    HDMI_B ──► 显示器

  按键 ──► 控制状态机 ──► 指挥上面整条流水线
  音频 ──► I2S 打包 ────► 汇入 HDMI
```

## 四、模块分解：哪个难、哪个有现成的

| 模块 | 难度 | 参考例程有吗 | 你们要做的 |
|---|---|---|---|
| 按键消抖 + 状态机 | ⭐ | — | 自己写，很简单 |
| BMP 解析 | ⭐⭐ | 有 | 自己写（注意 BGR 顺序、行 4 字节对齐） |
| SD/TF 卡 SPI 读取 | ⭐⭐⭐ | **有** | 理解后接入 |
| I2S 音频 | ⭐⭐⭐ | **有** | 理解后接入 |
| 时钟 / PLL / 复位 | ⭐⭐⭐ | **有**（含上电防抖设计） | 参考 |
| SDRAM 控制器 | ⭐⭐⭐⭐ | **有** | 最难，但可复用 |
| HDMI / TMDS 输出 | ⭐⭐⭐⭐ | **加密 IP** | **只能调用，不能改** |
| **帧缓存调度 + 像素处理** | ⭐⭐⭐⭐ | **没有** | **← 你们的核心工作，也是差异化所在** |

**关键判断**：底层接口基本都有现成的，**你们真正的活儿在"上层架构 + 像素处理"**——这也是拉开分差的地方。**方向是对的。**

### 🔴 必须补（不补做不下去）

1. **TD 工具链全流程** —— 建工程、约束、综合、布局布线、生成位流、下载
   - 资源：`8_FPGA学习资料/安路软件使用完整流程.pdf`
   - 资源：`2_Example/DEMO实验介绍/0_安路TD软件使用流程.pdf`
   - 资源：TD 自带 `doc/TD_User_Guide_V6.2.pdf`

2. **时序约束基础** —— 看懂 `.sdc`，知道怎么加时钟约束
   - 资源：参考例程的 `constraints_source/timing.sdc`
   - 资源：TD 自带 `doc/Tools_UG`

### 🟠 应该了解（影响设计质量）

3. **HDMI / TMDS 基本原理** —— 知道像素时钟怎么来、为什么需要 5x 时钟、数据岛是什么
   - 资源：`lab_ex5_i2s/doc/APUG092_HDMI1.4b_Transmitter_V1.0.docx`
   - 注意：发射核是**加密的**，只需理解接口不用理解内部

4. **SDRAM 工作原理** —— 行/列/体、刷新、突发
   - 资源：`6_EG4S20数据手册`

5. **跨时钟域（CDC）** —— 异步 FIFO、握手
   - 你们 ysyx 可能没深接触，但视频系统必须有
   - 资源：参考例程里的 `afifo_*` IP

### 🟡 用到再学（成本低）

6. **BMP 文件格式** —— 文件头结构、BGR 顺序、行补齐（半小时的事）
7. **FAT32 目录结构** —— 只需会"按文件名找扇区"
8. **I2S 时序** —— 分频 + 串并转换

### ⛔ 不需要学

- 流水线处理器（那是 ysyx B 阶段的事，这赛题用不上）
- 操作系统、特权级、虚存
- 高级图像算法（题目明确说"算法复杂度不作强制要求"）
