# 深度提示与对比度复位

训练面板保留档位数字，文字统一为0待测、1过浅、2合适、3过深。英文显示WAIT、LOW、GOOD、DEEP，仍使用五字符槽，右侧输入类型标识不变。中文标签使用现有16×16点阵；浅、深字形由同一份Noto CJK字体生成，基础字符ID 0～130及其位图保持不变。

本次只修改显示文案及对比度的复位档，不改ADC采样、滤波、峰值检测、分档阈值和按压统计。ADC路径继续保留未标定标识，接触演示路径继续保留演示输入标识；档位不是厘米数值。

`contrast_controls`的默认档3对应100%。本次将视频端`contrast_video`和OSD帧快照`frame_contrast`的复位值由4改为3，使复位时的图像处理与参数显示均使用100%。按K6后的50%、75%、100%、125%、150%循环保持不变。

独立参考表同时更新了全屏中文、完整英文训练面板和四档中英文字行。检查覆盖四档、两种语言、两类输入，以及帧内状态保持、训练区边界、字幕、转场和复位。现有启动测试补充了视频对比度复位断言，现有OSD测试补充了帧快照复位断言。

11项定向RTL仿真通过：中文ROM、中文字幕、完整中文屏幕、四档中英文文字、OSD帧状态、叠加功能、完整英文训练画面、转场与音频条带、对比度按键、对比度RGB以及顶层启动音画控制。四档文字测试比较57344个像素，完整中文屏幕测试比较2457600个像素。最终测试输入哈希与交付文件一致。
