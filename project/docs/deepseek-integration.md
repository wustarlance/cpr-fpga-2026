## 采用与修正

- 采用 DeepSeek 的 `contrast_rgb` 和 `font5x7_rom`，保留三个模块的约定接口。对比度的 signed 向下取整、饱和、通道顺序与独立期望表一致；字模匹配原32个图案。
- 修正 `scroll_text`：补齐组合辅助变量默认赋值，把地址计算与字模像素选择分开，使地址路径不读取字模数据。没有新增 RGB/像素流水寄存器。
- 返回的三个 `.mem` 与任务包期望表逐字节相同，SHA256一致。本次运行和交付沿用原始期望表，逐项记录其哈希。
- 原对比度和字模自检独立复跑通过；原滚动全文扫描在本机60秒时限内未结束，不能登记为通过。补充独立计数参考检查，覆盖暂停期间仍有帧事件、默认完整回绕、64字符/8空格与255帧节奏、复位、裁剪和字模联调；随后压缩重复扫描供默认30秒回归运行。
- 返回的 `run_tests.py` 缺少外部超时、明确PASS和失败文本检查。本次接入现有严格运行器，加入fixture哈希与plusargs，空运行或打印失败仍必须拒绝。
- 补齐并统一新增TD登记项的全局编译顺序；加入ADC mailbox端点日志，使已有验证脚本可以记录实际12+12个端点。未改时钟、引脚、ADC、SDRAM、FIFO或时序例外。

## 已接入的行为

视频路径为：底图/无图背景 → 原亮度模块 → 对比度模块 → 固定 OSD 与底部字幕 → HDMI。显示参数在VS下降沿锁存；文字自身颜色不随底图参数变暗。

字幕窗口为x16～623、y448～463，5×7 ASCII字模2倍显示，每3个帧事件左移1像素。内容随帧快照模式选择：教学、自动和训练；ADC训练保留`PRESS UNCAL`。自动展播暂停时字幕停止，继续时恢复。中文字体、训练底图与右侧数据分区仍是独立待办，当前训练模式仍保留原纯色反馈页。

对比度用SW1～SW3设置，下表代码顺序为**SW3 SW2 SW1**，1为拨码输入高：

| 拨码代码 | OSD档位 | 倍率 |
|---|---:|---:|
| 000 | 2 | 1.00 |
| 001 | 0 | 0.50 |
| 010 | 1 | 0.75 |
| 011 | 3 | 1.25 |
| 100 | 4 | 1.50 |
| 101～111 | 2 | 1.00 |

输入经过两级同步及20ms稳定过滤。默认按键训练演示中，拨码仍模拟深度，所以保持进入训练时的对比度；ADC和外部接触模式使用独立压力源，可继续调节。独立板载亮度/清场按键映射本次没有增加。

严格门槛仍拒绝这些结果，未把严重告警降级。实际记录的严重告警类别为 **PHY-5079, PHY-7002, USR-6135**：

- `USR-6135`：系统、视频与音频三个PLL的反馈路径在本地网络上，补偿延迟不可预测。
- `PHY-5079`：已从CTS Local Wire Summary定位到`ext_mem_clk_sft`对应的`U3/u2_ram/SDRAM_CLK`网络（ADC顶层带`u_board/`前缀），PLL驱动、一个接收端，采用本地布线。该网络是内置SDRAM的移相时钟，需要结合厂商规则复核，不能凭正裕量认定告警无害。
- `PHY-7002`：内置SDRAM宏在中间布局阶段重新定位；本机流程阶段文本与旧运行器识别条件不同，目前保守保留为未通过项目。

PLL包装、IPC及约束与基线一致；这只能说明本次没有改这些输入，不能证明告警无害或与新布局无关。后续需核对时钟网络/厂商规则并在实际使用的TD版本重新验证；不得用宽域false-path、多周期或简单忽略告警取得通过。
