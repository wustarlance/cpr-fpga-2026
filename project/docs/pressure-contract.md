# 压力采样和按压事件接口

本接口用于 HX4S20 / EG4S20BG256 心肺复苏训练原型。原始 ADC 输出和内部压力值均为无符号 12 位**码值**，不代表已经标定的毫米、厘米或牛顿。默认阈值仅供逻辑联调，机械结构、传感器、电阻网络和实测曲线确定后再标定。

## 时钟与复位

`pressure_normalize` 和 `peak_detect` 的所有输入、输出属于同一 `clk` 域。上游 ADC 控制器必须先将 EOC 与完整数据通过一个一致的采样传输机制送入该域；逐位同步原始数据不能保证字的一致性。配套 `sample_mailbox` 在 ADC 与处理时钟之间传输完整 12 位码值。

`rst_n` 异步拉低清除状态，释放应由所属时钟域的复位同步器完成。输入在有效上升沿前满足该域时序。两个模块均无背压：每个有效上升沿接受一次采样，不丢弃连续有效的输入。

## `pressure_normalize`

端口为 `clk`、`rst_n`、`adc_valid`、`adc_data[11:0]`，输出为 `pressure_valid`、`pressure_data[11:0]`。参数：

| 参数 | 默认值 | 含义 |
|---|---:|---|
| `RELEASE_BASELINE` | 3000 | 完全释放时的原始 ADC 码值，合法范围 0–4095 |
| `FALLING_WITH_FORCE` | 1 | 1：施压时原始 ADC 码值下降；0：施压时码值上升 |
| `FILTER_SHIFT` | 2 | 仅支持 0（直通）或 2（四点均值）；其他值在 elaboration 阶段报错 |

下降方向计算 `max(RELEASE_BASELINE - adc_data, 0)`；上升方向计算 `max(adc_data - RELEASE_BASELINE, 0)`。两操作数均限制在 12 位范围，差值不会超过 4095，负差截断为零。

直通模式在采样被接受的上升沿后更新输出，`pressure_valid` 对应该输入。均值模式只保存有效样本，先等待完整窗口；第 `2**FILTER_SHIFT` 个有效样本及其后每个有效样本更新均值，向下取整。没有有效采样的时钟不进入窗口，也不推进预热计数。四点均值中，第 4 个有效输入首次产生有效输出，稳态每个有效输入可产生一个输出；信号特征被窗口平滑，但没有额外的系统时钟流水级。直通与均值输出均在接受沿后可用，下游同步模块于下一上升沿读取。

例如直通模式在上升沿 N 接受输入，经该沿的非阻塞赋值更新后输出对应结果；下游同步模块在上升沿 N+1 读取此结果。这里的「直通」仍是寄存输出，不是组合旁路，也不再额外延迟到 N+2。

无效时钟将 `pressure_valid` 拉低并保持上次 `pressure_data`。连续有效输入允许有效输出连续为高；每个上升沿仍表示一个不同采样。复位将输出、历史窗口、计数和累加器全部清零，并重新预热。四点累加器宽度为 14 位，可以容纳最大总和 `4*4095=16380`。非法 `FILTER_SHIFT` 值进入具名错误模块实例，正常 0/2 配置不产生该实例；错误分支不声明采样数组，不会因负数或过大值先扩张数组。

默认分压器中 FSR 接地、固定电阻接电源；FSR 电阻随压力下降时，分压电压下降，因此先采用下降方向。真实 ADC 码值方向和释放基线仍须实测。不得把归一化后的压力峰值直接标作按压深度。

## `peak_detect`

输入为 `clk`、`rst_n`、`enabled`、`clear_session`、`sample_valid`、`sample_data[11:0]`；输出为 `peak_valid`、`peak_value[11:0]`、`depth_grade[1:0]`、`in_press`。有效采样来自归一化接口。

| 参数 | 默认值 | 条件 |
|---|---:|---|
| `RELEASE_LEVEL` | 100 | 完全释放：压力码值 `<= RELEASE_LEVEL` |
| `TRIGGER_LEVEL` | 150 | 开始按压：压力码值 `>= TRIGGER_LEVEL` |
| `TARGET_LOW` | 800 | 目标峰值下边界，包含该边界 |
| `TARGET_HIGH` | 1600 | 目标峰值上边界，包含该边界 |

参数须满足 `0 <= RELEASE_LEVEL < TRIGGER_LEVEL <= TARGET_LOW <= TARGET_HIGH <= 4095`。阈值均属于归一化后、滤波后码值域，参数合法性由实例化方保证。源码没有参数顺序检查或非法配置故障输出；比较使用转换到 12 位的阈值，超范围值可能被截断。违反上述约定的配置不受支持，不保证拒绝启动、停止计数或自动报告故障。触发/释放阈值重叠也可能导致错误触发，不能一概描述为「永远无法武装或触发」。默认阈值满足约定，本次不修改 RTL 或增加故障端口。

1. 复位、清场和停用后先等待一次有效的完全释放样本，再允许触发。此时持压或在停用期间释放不能重新武装；重新启用后仍须亲自观察释放。
2. 已武装时，低于触发阈值的噪声不会开始按压。触发后 `in_press=1`，对每个有效采样追踪最大值。
3. 只有有效采样回到完整释放阈值才完成一次按压。中间回落、包括从峰值下降 25%，仍属于原按压。完成时 `in_press=0`，输出捕获峰值和等级。
4. `peak_valid` 是**一个系统时钟**的完成脉冲，下一时钟清零，不依赖下一次 `sample_valid`。重复释放不会重复完成；下一按压需要再次达到触发阈值。

| `depth_grade` | 码值分类 |
|---:|---|
| 0 | 复位、停用、清场后的未知状态 |
| 1 | 峰值 `< TARGET_LOW`：浅 |
| 2 | `TARGET_LOW <= 峰值 <= TARGET_HIGH`：目标 |
| 3 | 峰值 `> TARGET_HIGH`：深 |

`peak_value` 和 `depth_grade` 在完成后保持，供下游在脉冲时读取；复位、`clear_session` 或 `enabled=0` 清零。停用或清场在任意时钟生效，优先于该时钟的采样与完成，并丢弃未释放的在途按压。无有效采样时不会更新时间或峰值；当前版本没有基于时长的传感器故障判断，持续持压不会凭空完成。ADC 超时/链路故障由上游报告；若后续增加持压故障或位移标定，须另行规定时间单位、计时条件及异常事件语义。

## 验证范围

`tb_pressure_normalize.v` 检查两种极性、零/满量程边界、四点均值预热与取整、连续和不规则有效间隔、无效时数据保持、复位和未满窗口丢弃。`tb_peak_detect.v` 检查触发/释放边界、浅/目标/深等级两侧边界、最大峰值、噪声、一按一次、未释放回落、稀疏采样时单时钟脉冲、清场/停用/复位后的重新释放。

测试遇到不匹配或超时使用 `$fatal(1, ...)`，成功末尾输出 `PASS`。这些测试验证数字接口语义，不能证明 ADC 模拟精度、实际压力/位移标定、真实采样时钟或硬件功能。

ADC 时序与管脚依据：本机官方包中的 `EG4S内部ADC使用指南.pdf` 和 `EG4S20数据手册.pdf`；配套核对事实见 `anlogic-hx4s20c` 技能的 `references/adc-and-board.md`。本模块没有修改原 PDF、参考工程或 ADC 原语模型。

## `sample_mailbox` 数据跨域

源域接口为 `src_clk`、`src_rst_n`、`src_valid`、`src_data[11:0]`，状态为 `src_busy`、`overflow_sticky`；目的域接口为 `dst_clk`、`dst_rst_n`，输出为 `dst_valid`、`dst_data[11:0]`。

源域上升沿 `src_valid && !src_busy` 接受一个字，锁存到 `src_hold` 并翻转请求 `req_toggle`。请求经过目的域 `req_meta`、`req_sync` 两级同步；检测到新请求后再等待一拍，捕获稳定的 `src_hold` 到 `dst_data`，产生一拍 `dst_valid` 并发出应答 `ack_toggle`。应答经过源域 `ack_meta`、`ack_sync` 两级同步后清除 `src_busy`。数据总线靠从接受到应答的保持协议保证一致性，没有逐位独立同步。

`src_busy=1` 时收到新的 `src_valid` 将丢弃该新字，设置 `overflow_sticky`，不覆盖在途数据、不产生该字的目的事件。此标志持续到共同复位。发送方若能等待 `!src_busy` 就不会主动丢样；无法停顿的 ADC 发送方须结合该标志检查采样频率和忙时间。目的端没有背压；有效输出保持一个目的时钟，数据保持到下一次完整传输或复位。

两域复位必须**共同异步断言，分别在各自时钟域同步释放**。共同复位丢弃在途请求，清除有效信号、数据、请求/应答和溢出状态。此实现不支持单侧独立复位；某侧的 PLL 失锁若只复位本域，会破坏 toggle 协议的请求/应答关系，顶层须将其纳入共同复位原因。

延迟取决于两个时钟的边沿相位和同步级，没有固定的共同系统时钟数。两级同步、下一拍捕获和应答返回都必须计入最大采样频率评估。同步器和跨域稳定总线的布局/约束仍须在实际 TD 工程验证；数字仿真不模拟亚稳态。寄存器 `src_hold`、`dst_data`、`req_meta`、`ack_meta` 保留清晰名称供约束定位。

`tb_sample_mailbox.v` 用 14 ns 与 22 ns 的时钟周期检查非整数频率比、每字一次与顺序、单源时钟请求、空闲无事件、忙时丢弃与粘滞溢出、共同复位取消在途数据、复位后继续传输。测试按源域真实接受沿记录预期字，不将已拒绝的字记作应送达数据。
