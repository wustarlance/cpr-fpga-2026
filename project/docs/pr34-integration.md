## 与本地缩放缓存的整合

本地四槽全缓存和加载时最近邻缩放保留在主工程中。`SCALE_ENABLE=1` 的主顶层使用四个固定 SDRAM 槽；`SCALE_ENABLE=0` 保留 PR 的旧调度路径，用于恢复/兼容测试。缩放读图器也接入了 PR 的取消、超时、错误码和有限重试接口。

已解决的重叠文件是 `project/rtl/SD/sd_card_bmp.v`、`tests/sim/tb/tb_sd_buffer_ownership.v` 和 `tests/sim/README.md`。PR 与干净 `main` 本身没有 Git 冲突；冲突来自恢复本地未提交缩放改动时，两套 SD 调度器同时修改同一文件。
